## 1. 目标与范围

**目的**：把重写稿做成一个独立的引导站。读者每页只做一个步骤，用页脚的上一步/下一步推进，照着走就能完成从准备住宅 IP 到订阅 claude 的全过程；想弄懂原理的读者切到原理视图，读到的是一篇完整的原理文章。

**网站名称** [要求]：「Re:从零开始订阅 claude」，取自番剧《Re:从零开始的异世界生活》，同时表示教程从零开始讲。英文副标题「Re:Zero − Starting Life with Claude」。项目仓库名 `rezero-subscribe-claude`。

**目标用户**：作者博客的读者，会用代理但不熟悉这套流程。读者会同时用手机和电脑，通常一边看一边在另一台设备上操作。

**成功标准**：
- 只想照做的读者只看操作视图，选好自己的方案和手机后一路点“下一步”走完，不需要看别的文章。[要求]
- 想弄懂原理的读者在任意步骤切到原理视图，看到的是原理版的整页正文。[要求]
- 原理版目录里的每一页在引导站里都有自己的页面，路线的分叉和汇合与原理版目录一致。[要求]
- 页面上没有“默认”标记和任何阅读记录。[要求]
- 站点有自己的 logo，前端视觉按新的设计重做。[要求]

**首期范围（v2.0）**：
- 重写稿的全部页面迁入：两版的同名页合成一个步骤，原理独有步骤、旁支页、参考页按 §5 处理。
- 按 §5 重建路线图和全部 URL。
- 原理/操作两种视图整页切换。
- 去掉默认路线和阅读记录相关的界面和逻辑。
- 新的视觉设计（设计令牌、页面结构）和 logo（含 favicon）。

**非目标**：
- 账号、登录、评论、留言、统计埋点。
- 和博客原文章或重写稿自动同步；重写稿改动后，由作者决定何时迁入。[选定]
- 多语言。
- 旧 URL 的跳转页：站点还没部署过（delivery.md），不存在需要保留的已发布 URL。[选定]
- 由 Agent 撰写重写稿以外的新内容。重写稿里的 TODO 原样保留，按 FR-21 呈现。
- 确定部署位置和域名（Q-01）。

**优先级**：P0 是新路线图 + 新 URL + 整页视图切换 + 去掉默认和记录；P1 是新视觉设计和 logo；P2 是步骤视频。

## 3. 三级边界

**Always**
- 每个步骤、选择页、参考页都有稳定的英文标识和独立 URL；v2.0 发布以后，URL 不随内容调整而改变。
- 构建时校验所有链接和路线，失败就阻止构建（FR-61）。
- 推广链接旁保留“是否亲自用过”的说明；前言、免责声明保留成本和风险提示。
- 手机和电脑两种宽度下都能完整阅读和操作。
- 页面不依赖国内无法访问的第三方资源才能显示，例如字体 CDN 或统计脚本。

**Ask first**
- 新增、删除或合并分叉点；把某一页移进或移出上一步/下一步序列。
- v2.0 发布后改变步骤标识或 URL 规则。
- 引入需要后端或数据库的能力。
- 改写重写稿的技术操作（命令、脚本版本、商家、优惠码）。迁移时只做拆分和排版，不改实质内容。
- 引入重型前端框架、UI 框架或付费服务。

**Never**
- 账号、评论、统计、广告等范围外的功能。
- 把读者的选择发送到任何服务器。
- 在页面上显示“默认”选项，或显示阅读记录（继续上次、已读标记、清除进度）。
- 在内容里编造作者没有提供的方案或数据，或者把“未验证”写成“已验证”。重写稿里的 TODO 只能按 FR-21 呈现。
- 放宽或跳过构建校验来让构建通过。
- 提交凭据、真实服务器 IP、节点链接、面板账号等敏感信息（包括截图里未遮盖的部分）。
- 使用番剧的图片、角色，或直接复制、描摹番剧的 Logo 文件（logo 的做法见 FR-70）。

## 4. 用户场景与流程

**S1 照做的新读者**：打开首页 → 看到 logo、站名和目录 → 点“从第 00 章开始” → 前言 → 免责声明 → 清理旧账号和配置（操作视图下跳过“整体思路”）→ 选择方案（选方案三）→ 方案三：直接买住宅节点 → 导入代理软件 → 测 IP 质量 → 防泄漏 → 改时区 → 选择手机系统（选 iPhone）→ iPhone 三步 → 注册 Gmail → …… → 注册 claude → 订阅 → iPhone 订阅各步 → 订阅之后 → 致谢 → 后记 → 回到首页。

**S2 想学原理的读者**：在任意步骤切到原理视图，整页换成原理版正文；之后的步骤保持原理视图，“下一步”会经过整体思路、小结等原理独有步骤，直到读者切回。

**S3 换方案的读者**：在“选择方案”选方案一，走到“五、打开面板”可以点跳过，直接到“导入代理软件”；在“导入代理软件”点“上一步”，回到“五、打开面板”。之后在目录里改选方案二，再点“上一步”，回到“方案二：住宅 IP 服务器”。

**S4 收到答疑链接**：作者把“导入代理软件”的 URL 发给读者。读者在新浏览器打开，直接看到该步骤；因为还没选过方案，“上一步”指向“选择方案”。打开“iPhone：下载 Gmail”这种只属于一个选项的步骤时，按这个选项计算导航。

**S5 被封号**：在“先用两天”的正文里点“被封了：申诉解封”，看完点“回到：先用两天”，或直接点“下一步：修改 Google 账号地区”。

**S6 卡住查问题**：步骤里有链接指向常见问题或某篇实测，读者看完点“返回刚才的步骤”回到原步骤。

**异常分支**
- 浏览器禁用本机存储或在无痕模式下：功能照常使用，只是关掉页面后选择不保留。
- 读者打开不存在的 URL：显示“找不到这一页”和目录入口。
- 视频平台打不开：显示平台链接和“打不开可换平台/开代理”的提示，不影响阅读正文。

## 6. 功能需求

### 内容

- **FR-01 内容来源** [要求]：步骤和参考页的内容来自重写稿，迁入后在引导站单独维护。重写稿改动后，由作者决定何时重新迁入。
- **FR-02 步骤元数据**：每个步骤至少有：标识、标题、所属章节、原理版正文、操作版正文（原理独有步骤为空）、是否可跳过、跳过按钮文案（可选）、步骤视频信息（可为空）。
- **FR-03 内容完整迁移** [要求]：重写稿每个文件里的每一段、每张截图、每个外链和命令，都要在对应的视图里出现；命令、链接、优惠码和商家信息保持原样。两版的同名页标题一致。
- **FR-04 写法转换**：重写稿的 Obsidian 写法（双链、`|宽度` 嵌入、表格、代码块）正确呈现。站内双链改成指向对应页面；指向博客其他文章的双链（例如 `04技术/自建梯子…`、`04技术/读者实测…`）按 Q-11 处理。页脚的“上一步/下一步”由路线图生成，正文末尾手写的页脚不显示。

### 页面与导航

- **FR-10 一页一步**：沿用。页面顶部显示章节名和本章进度，页脚显示“上一步”和“下一步”（按钮写出目标页的标题）。进度按读者当前路线和当前视图计数；某个分叉点未选、无法确定总数时，只显示章节名。
- **FR-11 上一步/下一步** [要求]：按读者当前路线和当前视图计算。操作视图下绕过原理独有步骤。后记的“下一步”是“附录”，附录（路线的最后一页）的“下一步”是“回到首页”（v0.4）。
- **FR-12 分叉点选择页** [要求]：选择页正文是重写稿的“选择方案”“选择手机系统”，每个选项是一块可点击区域，**不标默认**。选择后进入该选项的第一个步骤，并记住选择。已经选过时，标出“当前选择”。选择页的“下一步”：已选时进入所选选项的第一步；未选时不显示“下一步”。
- **FR-13 汇合与未选** [要求]：分支最后一步的“下一步”指向汇合点；汇合点的“上一步”指向所选分支的最后一步。没有默认路线：分叉点未选时，汇合点的“上一步”指向该分叉点的选择页；“订阅”的“下一步”指向“选择手机系统”。
- **FR-14 改变路线**：沿用。读者可以随时在目录或选择页改选，之后的导航按新路线计算。
- **FR-15 可跳过步骤**：可跳过步骤在“下一步”旁边有跳过按钮，文案按步骤自定（例如“没被封，跳过”），默认“跳过”。点击后跳过当前路线上连续的可跳过步骤，到达其后的第一项。

### 视觉与 logo

- **FR-70 logo** [要求，2026-10-15 作者修订]：logo 是番剧《Re:从零开始的异世界生活》标题字的同款风格，把文字换成本站的中英文：中文「Re:从零开始订阅 claude」，英文「Re:Zero − Starting Life with Claude」。“Re:”部分在造型上和番剧保持一致，其余文字模仿番剧标题的字体风格。做法：对照参考图自己重绘成 SVG 路径，不直接使用或描摹番剧的 Logo 文件；字体只用允许转曲和商用的开源字体（如 OFL 授权的思源宋体），不在页面上加载外部字体。参考图（2026-10-15 选定，只看不入库）：中文看 B 站《Re:从零开始的异世界生活 新编集版》封面上的标题，英文看英文版标题 “Re:ZERO −Starting Life in Another World−”。从参考图看出的特征：“Re”是紫色细衬线；冒号和其余文字是黑色粗字；中文“从”小、“零”大，下面一行小号英文；英文 ZERO 是粗衬线大写，E 小一号并上移，R 下沉；副标题是加宽字距的窄体粗字，两端带短横。选定版式（2026-10-15 作者选 E 版）：中文两行，第一行“Re”（紫色细衬线）+ 黑色粗冒号 + 小号“从”+ 大号“零”；中间一行小号英文“Re: Zero − Starting Life with Claude”；第二行缩进，大号“开始”+ 小号“订阅”（中线偏上，对应原版“的”的位置）+ 衬线大写“CLAUDE”，其中 A 小一号上移、U 下沉，学英文版 ZERO 的错落。英文版是“Re:ZERO”加副标题“−Starting Life with Claude−”。草稿用的开源字体是 Cormorant Garamond（Re）、Cinzel（冒号、ZERO、CLAUDE）、思源黑体 Heavy（中文）、Roboto Condensed（小号英文），定稿时可按字形再换，前提是开源可转曲。用在首页、页眉；favicon 用“Re:”或其中一个字单独做，深浅两种配色下都清楚，缩到 16px 仍能辨认。
- **FR-71 前端视觉重做** [要求]：作者认为 v1 的视觉“从头丑到尾”，全部页面（首页、步骤页、选择页、参考页、目录、找不到页）的设计令牌、版式和组件都重做，不在 v1 基础上修补。方向（作者 2026-10-15 选定）：
  - **手册骨架 + Re:0 点缀**：步骤页仍以清楚、好照做为先；首页、logo、页眉和章节过场带 Re:0 的味道（标题字风格、“从零开始/回到起点”的意象）。
  - **主色跟 logo 一起定**：先定 logo，再从 logo 取主色，反推全站令牌。
  - **两种视图轻区分**：版式相同，只在页眉的切换控件和一条色带或标签上标出当前视图。
  
  具体设计写进 [design.md](design.md)（2026-10-15 作者授权 Agent 决定，见 Q-12）；不能违反第 0 节“不能倒退的已有行为”和 NFR。
