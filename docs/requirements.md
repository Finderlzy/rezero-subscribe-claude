## 1. 目标与范围

**目的**：把《如何订阅claude》的两篇原文章做成一个独立的引导站。读者每页只做一个步骤，用页脚的上一步/下一步推进，照着走就能完成从准备住宅 IP 到订阅 claude 的全过程。

**网站名称** [要求]：「Re:从零开始订阅 claude」，取自番剧《Re:从零开始的异世界生活》，同时表示教程从零开始讲。首页大标题和每个页面的浏览器标题都使用这个名称；只借用标题句式，不使用该番剧的图片或 Logo。

**英文标题** [要求]：「Re:Zero − Starting Life with Claude」，套用番剧英文名《Re:Zero − Starting Life in Another World》的句式。显示在首页中文大标题下方作为副标题 [选定]。

**项目仓库名** [要求]：`rezero-subscribe-claude`。

**目标用户**：作者博客的读者，会用代理但不熟悉这套流程。读者会同时用手机和电脑，通常一边看一边在另一台设备上操作。

**成功标准**：
- 只想照做的读者只看操作视图、沿默认路线或自选路线走完，不需要回到原文章。[要求]
- 想弄懂原理的读者在任意步骤切到原理视图，就能看到原理版对应的解释。[要求]
- 原文章覆盖的每个方案和分支，在引导站里都有自己的步骤页面。[要求]
- 每个步骤都有步骤视频的位置；视频录好后只需填写视频信息，不需要改页面结构。[要求]

**首期范围**：
- 原文章的全部内容迁入引导站：前言、开始之前、整体思路、一到七节的全部方案和分支、常见问题、致谢、后记。
- 操作视图和原理视图，并能切换。
- 多路线导航：分叉点选择页、汇合点、可跳过步骤、步骤目录。
- 步骤视频嵌入，视频未录好时显示占位。
- 阅读进度保存在本机，每个步骤有独立 URL。
- 构建产物是纯静态文件。

**非目标**（首期不做）：
- 账号、登录、评论、留言、统计埋点。
- 和博客原文章自动同步内容。[选定]
- 多语言。
- 确定部署位置和域名，留到架构或交付阶段再定。[要求]
- 由 Agent 撰写原文章以外的新内容。原文章没有的内容（例如安卓订阅、Clash Verge 下的 DNS 设置）由作者后续补写 [要求]；补齐之前以“内容待补”占位，见 FR-21。

**优先级**：P0 是完整步骤序列 + 上一步/下一步 + 两种视图 + 分叉路线；P1 是步骤目录、阅读进度、视频嵌入；P2 是视觉打磨。

## 2. 能力地图

| 模块 ID | 职责 | 依赖 |
| --- | --- | --- |
| M1 内容 | 以“每个步骤一个文件”维护步骤、常见问题、首页和完成页的内容与元数据（章节、路线归属、视频、操作内容、原理内容） | 无 |
| M2 路线 | 根据步骤元数据和读者的选择，计算任意步骤的上一步、下一步、所属路线、章节进度 | M1 |
| M3 页面 | 把步骤渲染成页面：视图切换、步骤视频、页脚导航、步骤目录、首页、完成页、常见问题 | M1、M2 |

## 3. 三级边界

**Always**
- 每个步骤都有稳定的步骤标识和独立 URL，已发布的 URL 不随内容调整而改变。
- 构建时校验所有链接和路线，失败就阻止构建（FR-61）。
- 推广链接旁保留“是否亲自用过”的说明；“开始之前”保留成本、风险提示和免责声明。
- 手机和电脑两种宽度下都能完整阅读和操作。
- 页面不依赖国内无法访问的第三方资源才能显示，例如字体 CDN 或统计脚本。

**Ask first**
- 新增、删除或合并分叉点，或者改变默认路线。
- 改变步骤标识或 URL 规则。
- 引入需要后端或数据库的能力。
- 改写原文章的技术操作（命令、脚本版本、商家、优惠码）。迁移时只做拆分和排版，不改实质内容。
- 引入重型前端框架或付费服务。

**Never**
- 账号、评论、统计、广告等首期范围外的功能。
- 把读者的进度或选择发送到任何服务器。
- 在内容里编造作者没有提供的方案或数据（例如安卓订阅步骤），或者把“未验证”写成“已验证”。缺内容的地方只能用 FR-21 的占位。
- 放宽或跳过构建校验来让构建通过。
- 提交凭据、真实服务器 IP、节点链接、面板账号等敏感信息（包括截图里未遮盖的部分）。

## 4. 用户场景与流程

**S1 照做的新读者**（默认路线）：打开首页 → 读前言 → 点“直接开始” → 开始之前（确认前置条件和风险）→ 整体思路 → 节点方案选择页（选方案一）→ 买服务器 → 白嫖住宅 IP → 连接服务器 → 运行脚本并导入节点 → 确认出口 IP → …… → 在 app 内订阅 → 订阅之后 → 完成页。全程用页脚的“下一步”推进，在电脑上操作时，可以用手机看视频。

**S2 想学原理的读者**：在任意步骤切到原理视图，看完“为什么”的内容后继续下一步。之后的步骤保持原理视图，直到读者切回。

**S3 其他路线的读者**：在节点方案选择页选方案三 → 购买住宅节点 → 导入节点 →（可选）配置分流 → 确认出口 IP（汇合点）。点“上一步”会回到方案三的最后一步，而不是方案一的步骤。

**S4 中断后回来**：读者第二天在同一个浏览器打开首页，看到“继续上次：<步骤名>”，点击后回到该步骤，路线选择保持不变。

**S5 收到答疑链接**：作者把某个步骤的 URL 发给读者。读者打开后直接看到该步骤，上一步和下一步按该步骤所属路线计算，必要时用本机已选路线补全。

**S6 卡住查问题**：步骤内容里有链接指向某条常见问题（例如“购买未完成”），读者看完后点“返回刚才的步骤”回到原步骤。

**异常分支**
- 视频平台打不开（例如没开代理时打不开 YouTube）：显示视频平台链接和“打不开可换平台/开代理”的提示，不影响阅读正文。
- 浏览器禁用本机存储或在无痕模式下：功能照常使用，只是不保存进度。
- 读者打开不存在的步骤 URL：显示“找不到这一步”和步骤目录入口。

## 6. 功能需求

### 内容

- **FR-01 内容单独维护** [选定]：引导站的步骤、常见问题、首页、完成页各自有独立的内容文件。首期初稿由作者授权后从两篇原文章拆分生成，之后单独维护，和原文章不互相同步。
- **FR-02 步骤元数据**：每个步骤至少写明：步骤标识、标题、所属章节、所属路线（或“所有路线共用”）、是否可跳过、步骤视频信息（可为空）、操作内容、原理内容（可为空）。
- **FR-03 内容完整迁移** [要求]：原文章中每个小节、每个“为什么”说明框、每张截图、每个外链和命令，都要在引导站某个步骤、常见问题、首页或完成页中出现。迁移时不改变命令、链接、优惠码和商家信息的实质内容（Ask first）。
- **FR-04 图片自带** [选定]：截图复制进本项目，不引用博客仓库路径。原文章里的 Obsidian 写法（双链、嵌入、Callout）在引导站中都要正确呈现，指向原文章的双链改为指向对应的步骤或常见问题。

### 页面与导航

- **FR-10 一页一步** [要求]：每个步骤单独成页，页面顶部显示章节名和本章进度（例如“一、准备住宅 IP · 2/5”，按读者当前路线计数），页脚显示“上一步”和“下一步”。
- **FR-11 上一步/下一步** [要求]：按读者当前路线计算。路线内的第一个步骤的“上一步”指向前一章所选路线的最后一步；路线内最后一个步骤的“下一步”指向完成页。
- **FR-12 分叉点选择页** [要求]：分叉点用选择页呈现，列出每个选项的适用人群和差别（例如方案一/二/三的对比表）。选择后进入该选项的第一个步骤，并记录选择。选择页上标出默认选项。
- **FR-13 汇合**：分支的最后一个步骤的“下一步”指向汇合点；汇合点的“上一步”指向读者所选分支的最后一个步骤。没有记录选择时，按默认路线计算。
- **FR-14 改变路线**：读者可以随时在步骤目录或选择页更改某个分叉点的选择，之后的上一步/下一步按新路线计算，已读步骤不受影响。
- **FR-15 可跳过步骤** [选定]：可跳过步骤的页面上，在“下一步”旁边提供“已有，跳过”，点击后跳到该步骤之后的那一步。步骤目录里标出可跳过步骤。
- **FR-16 步骤目录** [选定]：从任意页面都能打开目录，按章节列出全部步骤：当前路线的步骤正常显示，其他路线的步骤也列出且可点，但要和当前路线区分开；当前步骤高亮。
- **FR-17 独立 URL** [选定]：每个步骤、常见问题、选择页、首页、完成页都有独立且稳定的 URL，可以直接打开、刷新、分享。分支步骤的 URL 本身能确定它属于哪个分叉选项（S5）。
- **FR-18 首页** [要求/选定]：首页展示前言，提供“直接开始”按钮进入“开始之前”。有阅读进度时，额外显示“继续上次：<步骤名>”。致谢和后记**不放在首页**。
- **FR-19 完成页** [选定]：放致谢、后记和作者联系方式 [要求]，提供“回到目录”和“重新开始”。联系方式的具体内容由作者提供（见 Q-07）。
- **FR-20 常见问题** [要求]：常见问题是独立页面，不进入上一步/下一步的序列。从步骤链接进入时，页面提供“返回刚才的步骤”；直接打开时，提供常见问题列表和目录入口。
- **FR-21 内容待补占位**：原文章没有覆盖的路线（例如安卓订阅、Clash Verge 下的 DNS 设置）由作者后续补写 [要求]。补齐之前，步骤页面照常存在，正文明确写出“内容待补”，并给出原文章里已有的提示，不得编造步骤。作者补写时只需要替换该步骤的内容文件，路线和导航不需要改动。构建时列出仍是占位的步骤清单（提示，不阻止构建），方便作者跟踪还缺什么。

### 视图

- **FR-30 视图切换** [要求]：每个步骤页都有“操作 / 原理”切换。操作视图只显示操作内容；原理视图显示操作内容，再加上该步骤的原理内容。默认是操作视图。
- **FR-31 视图记忆** [选定]：读者切换后，之后打开的步骤沿用这个视图，直到再次切换。步骤没有原理内容时，原理视图显示“这一步没有额外原理”。

### 视频

- **FR-40 步骤视频** [要求]：每个步骤都有视频区域，同时支持 B 站和 YouTube（每个步骤可以填其中一个或两个）。有两个平台时，默认显示 B 站，可以切换。[选定]
- **FR-41 视频占位** [选定]：没有视频信息的步骤，在视频区域显示“视频制作中”，不影响上线。
- **FR-42 视频加载**：视频在读者点击或进入可视区域后才加载，加载失败时显示平台外链。

### 本机状态

- **FR-50 阅读进度** [选定]：读者打开某个步骤时，把该步骤和当前路线选择保存在本机浏览器。不上传到服务器。
- **FR-51 清除进度**：完成页和目录里提供“清除进度”，清除后首页不再显示“继续上次”，路线恢复为默认路线。

### 构建与校验

- **FR-60 静态产物** [选定]：构建结果是一组静态文件，放在任意静态文件服务器（例如作者自己服务器上的 Nginx）或 GitHub Pages 上就能运行，不需要服务端程序。
- **FR-61 构建校验**：构建时检查以下情况，任一项不通过就终止构建并指出具体文件：步骤标识重复；引用的步骤、常见问题或图片不存在；某条路线从“开始之前”沿下一步走不到完成页，或者出现环；某个分支没有汇合点；必填元数据缺失。

## 7. 非功能需求

- **NFR-01 设备适配** [要求]：在 360px 宽的手机竖屏和 1280px 以上宽的桌面浏览器中，正文、表格、代码块和导航都能完整使用，页面整体不出现横向滚动（宽表格和代码块允许在各自区域内横向滚动）。
- **NFR-02 可读性**：命令和代码块提供一键复制；截图可以点击放大。
- **NFR-03 国内可访问**：读者不开代理时，除视频平台外，页面的全部内容（正文、图片、样式、脚本）都能正常加载。判定方法：屏蔽 Google 和 YouTube 相关域名后访问，页面完整显示。
- **NFR-04 隐私**：页面不加载任何统计或追踪脚本。视频嵌入只在读者点击或进入可视区域后加载（FR-42）。
- **NFR-05 浏览器**：支持当前版本的 iOS Safari、Chrome、Edge、Firefox。
