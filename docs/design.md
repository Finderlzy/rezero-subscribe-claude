# 界面设计契约：Re:从零开始订阅 claude

- 状态：**v2.0 定稿（2026-10-15）**，对应需求 v0.3 的 FR-70、FR-71。作者 2026-10-15 授权 Agent 决定前端样式（需求 Q-12 关闭），本文的配色、字体和页面结构不再单独等作者确认草图；logo 是否像番剧标题（AC-20）仍由作者确认。上一版 v0.2 是 1.0.0 的设计，见 git 历史。
- 关联：[需求](requirements.md)、[架构](architecture.md)、[术语](../CONTEXT.md)
- 用途：实现页面（M3）时以本文为准。本文规定**做什么、为什么这么做**；具体值以 `src/styles/tokens.css` 为准，两边改动要同步，对比度由 `src/styles/tokens.test.ts` 实测。

## 1. 设计调研：学到了什么，怎么用

只提炼原则，不借用任何站点的版式、配色、字体、图标或文案（1.0.0 起的要求）。

| 来源 | 学到的原则 | 本站的做法（v2.0） |
| --- | --- | --- |
| [GOV.UK：Step by step navigation](https://design-system.service.gov.uk/patterns/step-by-step-navigation/) | 让人随时看到整条流程；“或”步骤要和普通步骤区分开；不要让用户在流程之间来回绕 | 目录按章节列出整条路线，分叉点显示成“或”分组；参考页只有“返回”，不接进序列 |
| [GOV.UK：One thing per page](https://www.gov.uk/service-manual/design/form-structure) | 每页只放一件事；分支只让用户看到和自己相关的内容 | 一页一步；分叉点是单独的选择页 |
| [NN/g：Wizards](https://www.nngroup.com/articles/wizards/) | 显示第几步、共几步；“下一步”写出去哪里；每一步包含完成它需要的全部信息 | 页首显示“第 n 步，共 m 步”；按钮写“下一步：<标题>”。v2.0 按作者要求**不做**“继续上次”，回访靠目录和可分享的 URL |
| [Diátaxis：Explanation](https://diataxis.fr/explanation/) | 操作和原理分开写，各自完整 | 作者把两者写成了两篇完整文章，所以视图切换换整页（ADR-0004），而不是在操作里插原理段落 |
| [web.dev：Third-party facades](https://web.dev/third-party-facades) | 第三方嵌入先放轻量门面，点击后再加载 | 沿用 1.0.0 的视频门面，不加载封面图 |
| [WCAG 1.4.8](https://www.w3.org/WAI/WCAG21/Understanding/visual-presentation.html)、[W3C clreq](https://www.w3.org/TR/clreq/) | 中文每行不超过约 40 字；标点按大陆规范，不断开省略号、破折号 | 正文 `max-width: 38em`；不替换原文标点；`line-break: strict` |
| [W3C 系统字体对照](https://w3c.github.io/clreq/others/system-font-mappings.html) | 中文字体按平台排序，拉丁字体在前 | 正文只用系统字体，不加载网页字体（NFR-03） |
| 番剧《Re:从零开始的异世界生活》标题字（只看不入库，需求 FR-70） | 识别度来自三处：细衬线的紫色“Re”、黑色粗字、大小错落；英文副标题是加宽字距、两端带短横的窄体字 | 只在 logo、页首“眉题”的两端短横、章节号上借这几个特征；不用番剧的图片、角色和配色以外的任何元素 |
| [frontend-ui-engineering](../.claude/skills/agent-skills/build/frontend-ui-engineering/SKILL.md) | 避免“AI 味”：渐变、到处大圆角、卡片网格、重阴影、空洞的 Hero | §6 拒绝清单 |

**读者情况**（需求 §1、S1–S6）：一手拿手机看，另一台设备上照着做；每一步都要复制命令、对照截图；一半读者只想照做，一半想弄懂原理；收到作者发来的某一页链接，直接从中间开始。

## 2. 设计方向：“手册骨架 + Re:0 点缀”

作者选定（需求 FR-71）。站点是一本**放在键盘旁边、翻开就能照做的手册**，Re:0 的味道只出现在入口和分隔处，不进入正文。冲突时按顺序取舍：

1. **一眼知道我在哪**：每页顶部显示章节和第几步；当前是哪种视图，从页眉一眼看出。
2. **照做的东西最显眼**：命令、按钮名、截图是主角。
3. **单手能翻页**：手机上“上一步/下一步”固定在屏幕底部。
4. **安静**：一种强调色（logo 的紫），没有装饰插图、没有动效表演。
5. **点缀只在三处**：logo（首页、页眉、favicon）、眉题两端的短横（学番剧英文副标题 “−Starting Life in Another World−”）、“从零开始”的章节号（第一章是 `00`）。

**名字的处理**：logo 学番剧标题字的风格、换成本站的文字（FR-70），这是本站唯一借用番剧的地方。不使用 Anthropic / claude 的品牌色或标志，避免读者误以为是官方页面。

## 3. 视觉基础（设计令牌）

### 3.1 颜色

只用语义令牌，组件里不直接写色值。按 `prefers-color-scheme` 自动切换深浅，不提供手动切换。**主色取自 logo**：`--accent` 就是 logo 里“Re”的紫色；logo 定稿时如果调了这个紫，`--accent` 同步改，再跑对比度测试。

| --- | --- | --- | --- |
| `--bg` | 页面底色（纸色） | `#F8F6F1` | `#15141A` |
| `--surface` | 代码块、面板、选项块 | `#FFFFFF` | `#1F1D25` |
| `--text` | 正文；logo 的黑字；操作视图的色带 | `#1C1A22` | `#E8E5EE` |

| --- | --- | --- |

状态不能只靠颜色：当前项还要加粗并标 `aria-current`；其他路线带“其他路线”文字；当前视图还靠两段式切换的 `aria-pressed` 和文字。

### 3.2 字体与排版

```css
--font-sans: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial,
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC",
  "Source Han Sans SC", sans-serif;
--font-mono: ui-monospace, "SFMono-Regular", "Cascadia Code", "JetBrains Mono",
  Menlo, Consolas, monospace;
/* 只用于章节号和 404 的数字：系统自带的旧式衬线，呼应 logo 的衬线“Re”和 ZERO */
--font-numeral: "Iowan Old Style", "Palatino Linotype", Palatino, "Book Antiqua",
  Georgia, serif;
```

| 层级 | 手机（<720px） | 桌面 | 行高 | 字重 |
| --- | --- | --- | --- | --- |
| 页面标题 h1 | 26px | 32px | 1.3 | 800 |
| 章节过场的章节号 | 40px | 56px | 1 | 400（`--font-numeral`） |
| 正文内小标题 h2/h3 | 20 / 17px | 22 / 18px | 1.4 | 700 |
| 正文 | 17px | 18px | 1.8 | 400 |
| 眉题、标签、目录 | 14px | 14px | 1.5 | 500，字距 `0.06em` |
| 代码 | 0.875em | 0.875em | 1.6 | 400 |

- 标题用 800 字重的黑体，呼应 logo 里思源黑体 Heavy 的中文。
- 正文宽度 `max-width: 38em`；段落间距 `0.9em`；列表编号和正文左对齐。
- 原文的加粗是“照做的关键点”，用 700 字重，不改颜色。中西文空格以原文为准。

### 3.3 间距、圆角、阴影、图标

- 间距刻度：`4 8 12 16 24 32 48 64`（px）。
- 圆角：控件 4px，面板和选项块 8px，图片 4px；不用胶囊形。比 1.0.0 更收，贴近“手册”。
- 不用阴影表现层级，用 1px 边框；只有浮层用 `--overlay-shadow`。
- 图标全部自己画：内联 SVG，1.5px 线宽、24px 网格（菜单、左右箭头、返回、复制、已复制、播放、外链、关闭）。不引入图标库，不用 emoji。

## 4. 页面结构

### 4.0 页眉（首页以外的所有页面）

```
手机（<720px）                                   桌面（≥1100px）
┌────────────────────────────────┐           ┌──────────────────────────────────────────────────┐
│ [☰]  Re:              [操作│原理] │ ← 吸顶     │ Re: 从零开始订阅 claude                [操作│原理] │
├════════════════════════════════┤ ← 视图色带 ├══════════════════════════════════════════════════┤
```

- 左：logo 的“Re:”标记（`Logo variant="mark"`，高 24px）+ 站名（系统黑体 700，16px）；宽度 <480px 时只留标记。整块链接到首页，`aria-label="Re:从零开始订阅 claude 首页"`。
- 右：操作｜原理两段式切换（`aria-pressed`；没有 JS 时隐藏）。<1100px 时最左边多一个“目录”按钮（≥44×44px）。
- **视图色带**（FR-71“两种视图轻区分”）：页眉下边一条 3px 的满宽色带，操作视图用 `--text`，原理视图用 `--accent`。参考页没有视图，色带用 `--border`。切换时色带直接换色，不做动画。
- 页眉在所有宽度下吸顶，高度 56px；≥1100px 时左侧栏在页眉下方。

### 4.1 步骤页（最重要的页面）

```
手机                                         桌面（≥1100px）
┌──────────────────────────┐            ┌────────────┬──────────────────────────────────┐
│ 页眉 + 色带               │            │ 目录侧栏     │ — 01 准备节点和住宅 IP · 第 2 步，共 5 步 — │
├──────────────────────────┤            │（300px，    │ 二、购买服务器（h1）                  │
│ — 01 准备节点和住宅 IP ·  │            │  吸顶滚动）  │ [只有原理版 / 操作版还在写 提示]       │
│   第 2 步，共 5 步 —      │            │             │ 正文（≤38em）                        │
│ 二、购买服务器（h1）       │            │             │                                    │
│ 正文……                   │            │             │ [跳过 →]                            │
├──────────────────────────┤            │             │ ┌ ← 上一步 ────┐ ┌ 下一步 → ─────┐  │
│ [←]  [下一步：三、把服务…→] │ ← 吸底    │             │ │ 一、白嫖 ISP  │ │ 三、把服务器… │  │
└──────────────────────────┘            └────────────┴──────────────────────────────────┘
```

- **眉题**：`— <章节号> <章节名> · 第 n 步，共 m 步 —`，14px `--text-muted`，字距 `0.06em`，两端是短横（学番剧英文副标题的两端短横；短横用 CSS 伪元素画，不进文字内容，屏幕阅读器只读“准备节点和住宅 IP，第 2 步，共 5 步”）。章节号用 `--font-numeral`，从 `00` 开始。数不清步数时（FR-10）只写章节。
- **章节过场**：每章的第一页（含选择页）在眉题上方多一块：大号章节号（`--font-numeral`，`--accent`）+ 章节名 + 一条 1px 细线，上下各留 32px。这是“从零开始”的点缀，其余页面没有。
- **提示条**（在标题下、正文上，`--surface` 底、1px `--border`）：原理独有步骤在操作视图下写“这一页只有原理版。”；缺操作版的页面在操作视图下写“操作版还在写，下面是原理版。”（FR-21、FR-30）。
- **视频**：有视频信息时放在标题下面、正文上面（1.0.0 的门面）；没有时什么都不输出（FR-41）。
- **底部导航**：
  - 手机上吸底，高度 ≥ 56px，适配 `safe-area-inset-bottom`。“下一步”是主按钮（`--accent` 底），约占 2/3 宽，写出目标标题，太长就截断；“上一步”是只有箭头的次按钮（`aria-label="上一步：<标题>"`）。
  - 桌面放在正文结尾：两个大块链接，分别写方向和目标标题；主次同上。
  - 可跳过步骤在“下一步”上方多一个文字按钮，文案按步骤自定（默认“跳过”），后接 `→`（FR-15）。
  - 后记的“下一步”写“回到首页”（FR-11）；前言的“上一步”指向首页，写“首页”。
- **目录**：<1100px 时点“目录”打开全屏抽屉（`<dialog>`）；≥1100px 时常驻左侧栏。内容见 §4.5。

### 4.2 选择页（分叉点）

- 页眉、眉题、标题同步骤页；眉题只写章节（不计步数）。两种视图都有正文，切换规则同步骤页。
- 正文按原样显示；正文里每个选项的小节（架构 §3 M1“选项块”）显示成一块**选项块**：`--surface` 底、1px `--control-border`、8px 圆角，内边距 16px（桌面 24px），块间距 16px。块标题是原文的加粗段落，19px 700。
- 整块可点：块内第一个链接（这个选项的第一步）的点击区域用伪元素撑满整块；块内其他链接浮在上面，仍可单独点。悬停或聚焦时边框变成 `--accent`。
- 已选过的选项：左边框 4px `--accent`，标题右侧一个“当前选择”标签（`--accent-soft` 底、`--accent` 字），块上标 `aria-current="true"`。**没有任何“默认”字样**（FR-12）。
- 底部导航：“上一步”照常；“下一步”只在已选时出现，指向所选选项的第一步（FR-12）。

### 4.3 两种视图

- 两段式切换在页眉右侧，文字“操作”“原理”，按下的一段用 `--accent` 底、`--accent-contrast` 字。
- 切换后：整页正文换成另一版（ADR-0004），视图色带换色，页面滚回顶部（FR-30），焦点留在切换按钮上。不加动效；之后打开的页面沿用这个视图（FR-31）。
- 两种视图的版式完全相同，只有色带和切换按钮不同（FR-71）。

### 4.4 首页

```
┌──────────────────────────────────────────────┐
│                                              │
│   [logo：中文两行版，宽 ≤ 560px]               │  ← h1，aria-label 为站名
│   Re:Zero − Starting Life with Claude（logo 中间行）│
│                                              │
│   [ 开始 → ]                                  │  ← 主按钮，进入“前言”
│ ───────────────────────────────────────────  │
│   00  开始                                    │
│       前言 · 免责声明 · 整体思路 · 清理旧账号和配置 │
│   01  准备节点和住宅 IP                        │
│       选择方案                                 │
│         方案一：一、白嫖 ISP → …（可选）          │
│         方案二 / 方案三 …                       │
│       导入代理软件 · 测 IP 质量 · …             │
│   02  注册和订阅 …                             │
│   03  结尾 …                                  │
│   卡住了再看：常见问题 · IP 质量实测合集          │
└──────────────────────────────────────────────┘
```

- 没有页眉。顶部留白 64px（手机 32px），logo 左对齐，下面是“开始”主按钮，再下面一条细线和目录（FR-18）。
- 目录的结构和原理版目录页一致：四章 + 每章的页面，分叉点下列各选项的页面序列；章节号用 `--font-numeral` 的 `00`–`03`，这是首页唯一的装饰；首页目录是页面主体，字号用正文（不是 §3.2 的 14px），章名加粗。目录项都是链接，原理独有步骤后标“原理”。
- **没有**“继续上次”，也没有已读标记（需求 Never）。

### 4.5 目录（抽屉 / 侧栏）

- 按章分组，章名前是章节号。分叉点显示成“或”分组：各选项用短竖线连起来，旁边有“切换”控件（FR-14）。
- 当前路线上的页面正常显示；其他选项的页面也能点，但用 `--text-muted` 并带“其他路线”文字；当前页加粗、`--accent-soft` 底、`aria-current="page"`。
- 原理独有步骤标“原理”，在操作视图下弱化（它不在操作视图的“下一步”序列里）；可跳过步骤标“可跳过”。
- 末尾单列“卡住了再看”：常见问题、IP 质量实测合集。
- **没有**已读 ✓ 和“清除进度”（FR-16）。

### 4.6 旁支页、参考页、找不到页

- **旁支页**（被封了：申诉解封）：同步骤页，但眉题写“<章节名> · 旁支”；底部是“回到：先用两天”（次按钮）和“下一步：修改 Google 账号地区”（主按钮）（FR-19）。
- **常见问题**：页眉没有视图切换。h1“常见问题”，条目是 h2，每个 h2 有锚点。从步骤链接进来时，标题上方和正文末尾都有“← 返回刚才的步骤：<标题>”；直接打开时显示“打开目录”。没有上一步/下一步（FR-20）。
- **IP 质量实测合集 / 实测**：同常见问题；实测页底部另有“回到：IP 质量实测合集”。
- **找不到这一页**：眉题 `— 404 —`（数字用 `--font-numeral`），h1“找不到这一页”，一句说明，按钮“回到首页”（主）和“打开目录”（次）（AC-18）。

## 5. 交互与可访问性

- 全部用原生元素：`<a>`、`<button>`、`<dialog>`；页面开头有“跳到正文”。
- 焦点环 2px `--focus`，留 2px 间隔，不能去掉。手机上可点区域 ≥ 44×44px。
- 底栏吸底时，正文末尾预留等高空白。
- 隐藏的那版正文用 `display: none`，不进可访问性树（ADR-0004）。
- 没有 JS 时：页面可读，导航是构建时写好的（未选的分叉点处指向选择页），视图固定为操作视图，切换按钮和目录按钮隐藏（宽屏侧栏照常可点）。
- 本机存储不可用时不弹任何错误，功能照常，只是不保存。
- `prefers-reduced-motion` 时去掉所有过渡（本设计本来只有抽屉和看大图的淡入）。

## 6. 拒绝清单

评审 UI 时逐条核对：

- 照搬 GOV.UK、Starlight、MkDocs Material、博客现有主题的版式和配色；1.0.0 的墨绿配色和版式（作者认为“从头丑到尾”，FR-71 要求重做而不是修补）；
- 番剧的图片、角色、Logo 原文件或描摹（logo 只能按 FR-70 用开源字体自己排）；Anthropic / claude 的品牌色和标志；
- 紫色或靛蓝**渐变**、玻璃拟态、大圆角、重阴影（紫色只作为 logo 和强调的实色）；
- Hero 大图、首页卡片网格、装饰插图、界面里的 emoji；Re:0 元素超出 §2 第 5 条的三处；
- “默认”标记、“继续上次”、已读 ✓、“清除进度”（需求 Never）；
- 只写“下一步”、不写去哪里的按钮；用颜色作为唯一的状态标识；
- 加载网页字体、图标库、统计脚本、第三方封面图。
