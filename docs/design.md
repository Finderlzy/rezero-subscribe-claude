## 1. 设计调研：学到了什么，怎么用

### 1.0 定位、读者和目标感受

**网站**：把《如何订阅claude》做成一页一步的教程，有路线分叉（节点方案、手机系统），每一步有原理和操作两种视图（ADR-0004）。

**读者**（需求 §1、S1–S6）：大众，多数不是技术人员；一手拿手机看，另一台设备上照着做；每一步都要复制命令、对照截图；一半读者只想照做，一半想弄懂原理；收到作者发来的某一页链接，直接从中间开始。主题（服务器、代理、海外账号）本身让人紧张。

**目标感受**：作者说的“觉得很不错”拆成三条，每个设计决定都拿它们衡量：

1. **靠谱**：不像灰产页面，敢照着做。
2. **轻松**：一步一步，不慌，知道自己在哪。
3. **有人味**：看得出有人用心做，不是模板站。

**品牌关键词**：可信、安静、精确、从零开始（v2.1 是“说明书、手作感”，v2.2 D1 换成精确工具）。

只提炼原则，不借用任何站点的版式、配色、字体、图标或文案（1.0.0 起的要求）。

提炼的规律：一页一个焦点；单色墨水 + 纸底最可信、最耐看；编号本身就是视觉语言；个性只放在入口和转场。

v2.2 另看了 Josh Comeau 的个人站（joshwcomeau.com）：页头一条浅色色带放眉题和标题，一进页面就知道“这是哪一篇”；正文字号大、行距松，读着舒服；提示框是浅底加小标签。本站借了色带和阅读舒适度，不借它的天蓝、云朵、波浪边和卡通插画（§8 否决的想法）。

## 2. 设计方向：精确工具

站点是一件**干净、准确、照着做不会错的工具**（v2.2 D1）：纯白底、墨黑字、一种强调色（葡萄紫，来自 logo）；用细灰线、编号圆圈和留白组织页面，翻页只有一个黑色主按钮。命令和截图在干净的底上最清楚。Re:0 的味道只在 logo 和章首页的英文副标题里；Claude Code 的官方像素小形象趴在每页页头色带的右下角（D6，有分歧，见 §8）。冲突时按顺序取舍：

1. **一眼知道我在哪**：每页顶部的页头色带写“第 1 章 · 准备节点和住宅 IP · 第 2 步，共 10 步”和 h1；桌面左侧常驻目录高亮当前页。
2. **照做的东西最显眼**：命令、按钮名、截图是主角。
3. **单手能翻页**：手机上“上一步/下一步”固定在屏幕底部。
4. **安静**：紫色只用在链接、当前位置、眉题和“已选”上（D2）；橙色只属于小形象（D7）；没有装饰插图、没有动效表演；只讲原理的**说明图**可以有（§4.7）。
5. **点缀只在三处**：logo（首页、页眉、favicon）、章首页色带里的英文副标题 `− CHAPTER 01 −`、页头色带上的小形象。

**视觉语言**：

| 元素 | 用在哪里 |
| --- | --- |
| 浅紫页头色带（`--accent-soft`） | 每页顶部，放眉题和 h1（D4） |
| 1px 细灰线（`--border`） | 页眉下沿、侧边栏右沿、翻页上方、页脚上方、选项行和截图的边框 |
| 编号圆圈 | 选择页的选项行（1px `--control-border`） |
| 一个黑色主按钮（`--primary-bg`） | 每页只有“下一步”（首页是“从第 00 章开始”） |
| 留白 | 区块之间的唯一“装饰” |

**有人味从哪来**：靠“作者画给你看”：原理页的线稿说明图（§4.7）、编号的截图图版（§4.7）、章首页色带里一句这一章要做成什么（§4.1）。

**名字的处理**：logo 学番剧标题字的风格、换成本站的文字（FR-70），这是本站唯一借用番剧的地方。不使用 Anthropic / claude 的品牌色、标志或衬线和米色；唯一例外是 Claude Code 的官方像素小形象（D6、D7），每页页脚写明“本站是个人教程，与 Anthropic 无关。”

## 3. 视觉基础（设计令牌）

### 3.1 颜色

只用语义令牌，组件里不直接写色值。按 `prefers-color-scheme` 自动切换深浅，不提供手动切换。**主色取自 logo**：`--accent` 也是 logo 里“Re”的颜色（`--logo-re: var(--accent)`）。

和 v2.2 计划 §2 的两处不同：`--text-faint` 比计划的 `#71717a` 深一档，代码块上的复制按钮用它在 `--surface-muted` 上才达到 4.5:1；`--control-border` 用 `#8a8a93`（计划写 `#a1a1aa`），编号圆圈和控件边界在白底上要 ≥3:1。

要求：正文与背景 ≥ 4.5:1，大字和控件边界 ≥ 3:1，每一组都在 `tokens.test.ts` 里实测（含页头色带上的眉题、标题和次要文字，`--primary-fg` / `--primary-bg`，复制按钮）。

**用色规则**：紫色只用在链接、当前位置（目录当前项）、页头色带的眉题和“已选”上，不做大块底色（`--accent-soft` 是浅底，不算）；全页唯一的实心块是黑色主按钮。橙色只出现在小形象上（D7）。

状态不能只靠颜色：当前项还标 `aria-current`；其他路线带“其他路线”文字；已选的选项行有“已选”文字；当前视图靠分段控件的 `aria-pressed` 和文字。

### 3.2 字体与字号

```css
--font-sans: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial,
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC",
  "Source Han Sans SC", sans-serif;
--font-mono: ui-monospace, "SFMono-Regular", "Cascadia Code", "JetBrains Mono",
  Menlo, Consolas, monospace;
```

- 正文、标题、界面文字只用系统字体，不加载网页字体（NFR-03）。
- **标题字重 600**（`--fw-heading`，D3）：h1/h2/h3、章名、选项标题、按钮文字都用它；不用 700/800。苹果设备上是苹方中粗体；不写 500，因为微软雅黑没有 500，会退回常规体。
- **编号写成文字**（D10）：步骤页上的章和步一律写成“第 1 章”“第 2 步，共 10 步”，阿拉伯数字不补零。固定字形的大号编号（`Numeral`，Cormorant Garamond 500 等高数字，事先转曲）只留在首页的章级索引、首页和目录的章节号（`00`–`04`）和找不到页。
- **章首页的英文副标题**（`− CHAPTER 00 −` 到 `− CHAPTER 04 −`）也是固定字形，和 logo 中间那行英文同一种窄体（Roboto Condensed 700），五条，由 `scripts/build-logo.mjs` 生成。

| 层级 | 手机（<720px） | 平板（720–1099px） | 桌面（≥1100px） | 行高 | 字重 |
| --- | --- | --- | --- | --- | --- |
| 页面标题 h1 | 26px | 30px | 32px | 1.3 | 600 |
| 章首页色带里的章名 | 28px | 34px | 34px | 1.3 | 600 |
| 章首页的英文副标题 | 13px | 13px | 13px | 1.5 | 固定字形，字距 `0.3em` |
| 正文内小标题 h2/h3 | 20 / 17px | 21 / 18px | 22 / 18px | 1.4 | 600 |
| 正文 | 17px | 18px | 18px | 1.85 | 400 |
| 首页 logo 下的一句话 | 18px | 20px | 20px | 1.6 | 400 |
| 眉题、目录、标签 | 14px | 14px | 14px | 1.5 | 600 / 400，字距 `0.06em` |
| 选项标题 / 选项说明 | 17 / 15px | 17 / 15px | 17 / 15px | 1.5 | 600 / 400 |
| 截图编号、页脚、“← 上一步”、提示框小标签 | 13px | 13px | 13px | 1.5 | 400 / 600 |
| 代码 | 0.875em | 0.875em | 0.875em | 1.6 | 400 |

- 正文宽度 `max-width: 38em`（`--measure`）；段落间距 `0.9em`；列表编号和正文左对齐。
- 原文的加粗是“照做的关键点”，不改颜色。中西文空格以原文为准。

### 3.3 网格、间距、圆角、阴影、图标

- 断点：手机 <720px，平板 720–1099px，桌面 ≥1100px。
- 左右边距（`--gutter`）：手机 16px，平板起 32px。正文栏宽 `--content-width`（38em 加两侧边距），页头色带的内容、正文、页脚都用这个宽度、左缘对齐。
- **桌面（≥1100px）**：左侧常驻目录侧边栏宽 272px（`--sidebar-width`），右边一条 1px `--border` 竖线一直画到页脚底；正文区在剩下的宽度里居中。首页和找不到页没有侧边栏。
- **首页（桌面）**：内容最宽 1120px，左对齐，12 栏、栏间距 32px。封面主区占第 1–7 栏，章级索引占第 9–12 栏。
- 间距刻度：`4 8 12 16 24 32 48 64 96`（px；96 只用于首页顶部）。页头色带上下内边距 `--band-pad-y`：手机 24px，平板起 32px。
- 全站左对齐，没有居中的标题或按钮。
- 圆角：按钮、选项行、视图切换、目录当前项 8px（`--radius-control`）；提示框、代码块 10px（`--radius-panel`）；截图 8px（`--radius-image`）。不用胶囊形。
- 不用阴影表现层级，用 1px 细线；只有浮层用 `--overlay-shadow`。
- 图标全部自己画：内联 SVG，1.5px 线宽、24px 网格（菜单、左右箭头、复制、已复制、播放、外链、关闭）。不引入图标库，不用 emoji。说明图的线宽和图标一致。

## 4. 页面结构

网站地图：

| 页面 | 数量 | 设计目标 |
| --- | --- | --- |
| 首页 | 1 | 一眼建立“靠谱”的印象，知道从哪开始；看到完整目录（FR-18） |
| 步骤页 | 全部步骤 | 把这一步要做的事讲清楚；知道自己在第几章第几步；单手能翻到下一步 |
| 选择页（分叉点） | 2（选择方案、选择手机系统） | 让读者比较几个选项并选一个；不暗示“默认” |
| 旁支页 | 1（申诉解封） | 解决一个意外后回到主线 |
| 附录 | 1 | 正文结束后的入口，链到常见问题和 IP 质量实测合集 |
| 参考页 | 常见问题和 7 条问题（一问一页）、IP 质量实测合集和 6 篇实测 | 卡住时查；看完回到刚才的步骤 |
| 找不到这一页 | 1 | 不慌：回首页或打开目录 |

| 链接悬停 | 下划线从 1px 变 2px |
| 主按钮悬停 | 底色换 `--primary-bg-hover`，箭头向右移 4px |
| 选项行悬停 | 底色 `--surface-muted`、边框 `--control-border`，箭头右移 4px |
| 目录项悬停 | `--surface-muted` 底 |
| 复制 | 按钮文字变“已复制”，2 秒后复原，`aria-live` 播报 |
| 按下 | 所有按钮按下时下移 1px |

- `prefers-reduced-motion` 时去掉所有过渡和位移。
- 全部用原生元素：`<a>`、`<button>`、`<dialog>`；页面开头有“跳到正文”。
- 焦点环 2px `--focus`，留 2px 间隔，不能去掉。手机上可点区域 ≥ 44×44px。
- 固定字形的编号要有文字替代（读屏读“第 1 章”），装饰性的副标题和小形象对读屏隐藏。
- 隐藏的那版正文用 `display: none`，不进可访问性树（ADR-0004）。
- 没有 JS 时：页面可读，导航是构建时写好的（未选的分叉点处指向选择页），视图固定为操作视图，切换按钮隐藏；≥1100px 侧边栏照样可用，<1100px 的“目录”是指向首页完整目录的链接（FR-16）。
- 本机存储不可用时不弹任何错误，功能照常，只是不保存。

**三种宽度保持同一气质**：同一套白底、细线、页头色带和黑色主按钮；变化只有四处——桌面常驻侧边栏、平板和手机用抽屉；首页的章级索引只在桌面；底部导航在手机上吸底；小形象在手机上缩小一半。
