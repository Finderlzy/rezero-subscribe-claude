## 1. 设计调研：学到了什么，怎么用

### 1.0 定位、读者和目标感受

**网站**：把《如何订阅claude》做成一页一步的教程，有路线分叉（节点方案、手机系统），每一步有原理和操作两种视图（ADR-0004）。

**读者**（需求 §1、S1–S6）：大众，多数不是技术人员；一手拿手机看，另一台设备上照着做；每一步都要复制命令、对照截图；一半读者只想照做，一半想弄懂原理；收到作者发来的某一页链接，直接从中间开始。主题（服务器、代理、海外账号）本身让人紧张。

**目标感受**：作者说的“觉得很不错”拆成三条，每个设计决定都拿它们衡量：

1. **靠谱**：不像灰产页面，敢照着做。
2. **轻松**：一步一步，不慌，知道自己在哪。
3. **有人味**：看得出有人用心做，不是模板站。

**品牌关键词**：说明书、可信、安静、从零开始、手作感。

只提炼原则，不借用任何站点的版式、配色、字体、图标或文案（1.0.0 起的要求）。

## 2. 设计方向：“随身说明书 + 章节标题卡”

站点是一本**放在手边、翻开就能照做的说明书**（D1）：纸色底、墨黑字、一种强调色；用编号、细线和留白组织页面，不用卡片和装饰；Re:0 的味道只在入口和章节转场，不进入正文。冲突时按顺序取舍：

1. **一眼知道我在哪**：每页有章节和步骤编号；当前是哪种视图，从页眉一眼看出。
2. **照做的东西最显眼**：命令、按钮名、截图是主角。
3. **单手能翻页**：手机上“上一步/下一步”固定在屏幕底部。
4. **安静**：一种强调色（logo 的紫），没有装饰插图、没有动效表演；只讲原理的**说明图**可以有（§4.7）。
5. **点缀只在三处**：logo（首页、页眉、favicon）、眉题两端的短横（学番剧英文副标题 “−Starting Life in Another World−”）、每章第一页的**章节标题卡**（§4.1）。

**视觉语言只有四样**，全站所有元素都由它们组成，新加元素前先问能不能用这四样表达：

| 元素 | 用在哪里 |
| --- | --- |
| 编号（固定字形的衬线数字，§3.2） | 章节号、步骤编号、首页索引、404 |
| 1px 细线 | 分隔；`--border` 是普通分隔，`--text` 色的线只用于章节边界 |
| 一处紫色 | 每屏只有一个“最该点或最该看”的东西用紫（§3.1 用紫规则） |
| 留白 | 区块之间的唯一“装饰” |

**有人味从哪来**（D4）：靠“作者画给你看”，不靠装饰。三个落点：原理页的线稿说明图（§4.7）、编号的截图图版（§4.7）、章节标题卡上一句这一章要做成什么（§4.1）。

**名字的处理**：logo 学番剧标题字的风格、换成本站的文字（FR-70），这是本站唯一借用番剧的地方。不使用 Anthropic / claude 的品牌色或标志，避免读者误以为是官方页面。

### 3.2 字体与字号

```css
--font-sans: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial,
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC",
  "Source Han Sans SC", sans-serif;
--font-mono: ui-monospace, "SFMono-Regular", "Cascadia Code", "JetBrains Mono",
  Menlo, Consolas, monospace;
```

- 正文、标题、界面文字只用系统字体，不加载网页字体（NFR-03）。
- **编号用固定字形**（D7）：编号是全站主视觉，各设备自带的衬线差别太大（安卓上常常退回普通衬线），所以 `0`–`9` 和短横 `–` 用和 logo“Re”同一种细衬线（Cormorant Garamond 500）的**等高数字**，像 logo 一样事先画成图形，所有设备显示一样。旧式衬线默认的“小写数字”会让 `0` `1` 缩成半高，不用。用于：章节号、步骤编号、首页索引和目录的章节号、404。
- **章节标题卡的英文副标题**（`− CHAPTER 00 −` 到 `− CHAPTER 03 −`）也用固定字形，和 logo 中间那行英文同一种窄体（Roboto Condensed 700），只有四条，事先画好。
- 截图编号（“图 02-1”）字号小，用系统字体即可。

| --- | --- | --- | --- | --- | --- |
| 章节标题卡：章节号 | 64px | 80px | 96px | 1 | 固定字形 |

- 原文的加粗是“照做的关键点”，用 700 字重，不改颜色。中西文空格以原文为准。

### 3.3 网格、间距、圆角、阴影、图标

- 断点：手机 <720px，平板 720–1099px，桌面 ≥1100px。
- 手机左右边距 16px，平板 32px。
- **步骤页（桌面）**：正文栏（≤38em）在页面居中，宽 96px 的页边栏“悬挂”在正文栏左侧，中间隔 32px。页边栏不占正文的位置，所以页面重心略偏左，像一页翻开的书，右边留白。平板和手机没有页边栏，编号放在 h1 前。
- **首页（桌面）**：内容最宽 1120px，左对齐，12 栏、栏间距 32px。封面主区占第 1–7 栏，章级索引占第 9–12 栏（空出第 8 栏作呼吸）。
- 间距刻度：`4 8 12 16 24 32 48 64 96`（px；96 只用于首页顶部和章节标题卡上方）。
- 全站左对齐，没有居中的标题或按钮。
- 圆角：控件 4px，面板和选项块 8px，图片 4px；不用胶囊形。
- 不用阴影表现层级，用 1px 边框；只有浮层用 `--overlay-shadow`。
- 图标全部自己画：内联 SVG，1.5px 线宽、24px 网格（菜单、左右箭头、返回、复制、已复制、播放、外链、关闭）。不引入图标库，不用 emoji。说明图的线宽和图标一致。

## 4. 页面结构

网站地图：

| 页面 | 数量 | 设计目标 |
| --- | --- | --- |
| 首页 | 1 | 一眼建立“靠谱的说明书”的印象，知道从哪开始；看到完整目录（FR-18） |
| 步骤页 | 全部步骤 | 把这一步要做的事讲清楚；知道自己在第几章第几步；单手能翻到下一步 |
| 选择页（分叉点） | 2（选择方案、选择手机系统） | 让读者比较几个选项并选一个；不暗示“默认” |
| 旁支页 | 1（申诉解封） | 解决一个意外后回到主线 |
| 参考页 | 常见问题、IP 质量实测合集、各篇实测 | 卡住时查；看完回到刚才的步骤 |
| 找不到这一页 | 1 | 不慌：回首页或打开目录 |
| 目录抽屉 | 每页都能打开 | 看整条路线、跳转、改选分叉 |

路线：四章（`00 开始`、`01 准备节点和住宅 IP`、`02 注册和订阅`、`03 结尾`），两个分叉点，见 `src/content/route.yaml`。每章第一页带章节标题卡：前言、选择方案、选择手机系统、致谢。

### 4.0 页眉（首页以外的所有页面）

```
手机（<720px）                                   桌面（≥1100px）
┌────────────────────────────────┐           ┌──────────────────────────────────────────────────┐
│ [☰]  Re:              [操作│原理] │ ← 吸顶     │ [☰ 目录]  Re: 从零开始订阅 claude       [操作│原理] │
├════════════════════════════════┤ ← 视图色带 ├══════════════════════════════════════════════════┤
```

- 左：“目录”按钮（所有宽度都有，D5；≥44×44px；桌面带“目录”两字），然后是 logo 的“Re:”标记（`Logo variant="mark"`，高 24px）+ 站名（系统黑体 700，16px）；宽度 <480px 时只留标记。标记和站名整块链接到首页，`aria-label="Re:从零开始订阅 claude 首页"`。
- 右：操作｜原理两段式切换（`aria-pressed`；没有 JS 时隐藏）。
- **视图色带**（FR-71“两种视图轻区分”）：页眉下边一条 3px 的满宽色带，操作视图用 `--text`，原理视图用 `--accent`。参考页没有视图，色带用 `--border`。切换时色带直接换色，不做动画。

## 5. 交互、反馈与可访问性

**动效**（D11）：只有两处过渡，其余状态变化都是直接切换。

| 场景 | 表现 |
| --- | --- |
| 目录抽屉 | 从左侧滑入 200ms、减速曲线，遮罩同时淡入；关闭 150ms |
| 看大图 | 淡入 150ms |
| 翻页、视图切换、章节标题卡、色带换色 | 没有动画 |
| 链接悬停 | 下划线从 1px 变 2px |
| 主按钮悬停 | 箭头向右移 4px（不改颜色，避免再加一个紫色） |
| 次按钮、选项块悬停 | 边框变成 `--text`（选项块变 `--accent`，§4.2） |
| 复制 | 按钮文字变“已复制”，2 秒后复原，`aria-live` 播报 |
| 按下 | 所有按钮按下时下移 1px |

- `prefers-reduced-motion` 时去掉所有过渡和位移。
- 全部用原生元素：`<a>`、`<button>`、`<dialog>`；页面开头有“跳到正文”。
- 焦点环 2px `--focus`，留 2px 间隔，不能去掉。手机上可点区域 ≥ 44×44px。
- 固定字形的编号要有文字替代（屏幕阅读器读“第 2 步，共 5 步”“第 1 章”），装饰性的副标题对读屏隐藏。
- 底栏吸底时，正文末尾预留等高空白。
- 隐藏的那版正文用 `display: none`，不进可访问性树（ADR-0004）。
- 没有 JS 时：页面可读，导航是构建时写好的（未选的分叉点处指向选择页），视图固定为操作视图，切换按钮隐藏；“目录”按钮改成链接，指向首页的完整目录，保证任意页面都能到达目录（FR-16）。
- 本机存储不可用时不弹任何错误，功能照常，只是不保存。

**桌面、平板、手机保持同一气质的方法**：三种宽度用同一套四样视觉语言（§2）、同一套用紫规则和同一种左对齐；变化只有三处——页边栏在平板和手机上收进 h1 前，首页的章级索引在平板和手机上不显示，底部导航在手机上吸底。

**一致性检查（2026-10-16）发现并已修正的问题**：

1. 步骤编号原先写成全站总数（“共 34 步”），和 FR-10 的“本章进度”冲突 → 改成本章的第几步，从 `01` 起。首页按钮随之从“从第 00 步开始”改成“从第 00 章开始”。
2. 选择页、旁支页不计步数，页边栏顶端没有编号 → 改放“选择”“旁支”二字。
3. 数不清第几步时编号位置是空的，竖轴断了 → 放一条短横。
4. D1 提到的“点线”在任何页面都没有具体用处，等于多了一种分隔线 → 去掉，全站只有 1px 实线。
5. 视图切换按下时是紫底，和主按钮同屏时出现两个大块紫 → 改墨色。
6. 手机首页的章级索引和下面的完整目录重复 → 平板和手机不显示索引。
7. 桌面眉题和页边栏都写章节号 → 页边栏只写“共 m 步”，章节留在眉题。
8. 选择页的选项块像卡片，和“不用卡片”冲突 → 保留，它是整块可点的控件，写明是全站唯一带底色的块。

**否决的想法**：

| 想法 | 否决原因 |
| --- | --- |
| 以番剧章回为主体 | 主题感过头像同人站；不看番的读者困惑；削弱“靠谱” |
| 友好指南风（多色、贴纸、大圆角色块） | 焦点太多、模板化、过时快；和截图、命令抢注意力；太“轻松”会削弱信任 |
| 首页做全屏标题卡 | 居中的戏剧化构图和全站左对齐冲突；第一眼看不出从哪开始；提前用掉章节标题卡的仪式感 |
| 桌面上把步骤编号写在标题前（不要页边栏） | 说明书特征消失，变成普通文档站 |
| 手写字体、手绘圈注 | 中文手写体显得廉价；和工整编号是两套语言；圈注和截图抢视线。“作者在旁边提醒”改由页边栏小字承担 |
| 引导吉祥物 | 番剧相关角色有借用风险，原创角色难不俗；削弱“靠谱”；成为每页第二个焦点 |
| 只在 ≥1440px 常驻目录侧栏 | 常见笔记本宽度正好在 1280–1440px，换显示器就看到两种版式；宽屏仍是左侧两条竖栏 |
| 目录侧栏移到右侧、缩成本章步骤索引 | 又成三栏，左右两个次要焦点；编号重复；章内有分叉时没选路线就不知道列哪条 |
| 章节标题卡占满第一屏 | 从链接直接打开章首页的人第一屏没有可操作的东西；手机每章多滑一屏 |
| 章节标题卡只加强眉题 | 太弱，D1 补辨识度的那一笔就没了 |
| 编号沿用各设备自带的衬线 | 编号是主视觉，安卓上常退回普通衬线，D3、D6 的对比在一部分读者那里失效 |
| 章节标题卡入场动画 | 每进一章都要等动画，和“安静”冲突；仪式感靠版式就够了 |
| 沉浸式 3D、复古终端、粗野主义 | 好看但不适合大众教程 |
