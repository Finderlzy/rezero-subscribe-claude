## 1. 设计调研

### 1.0 定位、读者和目标感受

**网站**：把《如何订阅claude》做成一页一步的教程，有路线分叉（节点方案、手机系统），每一步有原理和操作两种视图（ADR-0004）。v3 起一个步骤可以有几个**小节**（合并页，FR-05）。

**读者**（需求 §1）：大众，多数不是技术人员；一手拿手机看，另一台设备上照着做；要复制命令、对照截图；一半只想照做，一半想弄懂原理；常常从作者发来的某一页链接直接进来。

**目标感受**沿用：**靠谱**（不像灰产页面，敢照着做）、**轻松**（知道自己在哪）、**有人味**（看得出有人用心做）。v3 的做法是：用大家见过的“技术文档站”外观换来“靠谱”和“知道在哪”，有人味交给 logo、小形象、说明图和截图图版。

## 2. 设计方向：文档站

站点是一份**排版干净的技术文档**：白底、墨黑字、紫色链接；左边是目录，右边一栏文字；标题是大号纯文字，二级标题下面一条细线；翻页是两行文字链接。冲突时按顺序取舍：

1. **一眼知道我在哪**：h1 上面的灰色眉题写章和步；侧边栏只展开当前章、高亮当前页、列出本页小节。
2. **照做的东西最显眼**：命令、按钮名、截图是主角；页面上没有别的色块和它们抢。
3. **长页也找得到**：合并页靠侧边栏的小节列表和顶栏搜索定位（FR-16、FR-24）。
4. **安静**：紫色只用在链接、当前项、主按钮（只有首页一个）和“推荐/当前选择”标记上；橙色只属于小形象（D7 沿用）。
5. **点缀只在三处**：logo（首页、顶栏、favicon）、顶栏的小形象、原理页的说明图。v2.2 的页头色带、章首页英文副标题 `− CHAPTER 01 −` 和章节一句话都去掉（FR-72）。

**名字的处理**沿用：logo 学番剧标题字的风格（FR-70），不使用 Anthropic / claude 的品牌色、标志或衬线；唯一例外是 Claude Code 官方像素小形象（D6、D7），每页页脚写明“本站是个人教程，与 Anthropic 无关。”

## 3. 视觉基础（设计令牌）

只用语义令牌。默认按 `prefers-color-scheme` 自动切换深浅；**用户 2026-10-22 决定在顶栏加昼夜切换**（放在原来视图切换的位置，取代原来的“不提供手动切换”），选了之后 `<html data-theme>` 以选择为准，见架构 §13.12（参考站没有深色模式，深色按同样的结构反推，FR-72）。`--accent` 仍是 logo 里“Re”的颜色。

- 字体栈不变（系统字体，中文在后，NFR-03）；等宽字体不变。

- **编号写成文字**（D10 沿用）。固定字形 `Numeral` 只剩找不到页的大号 `404`；章节号一律写成文字（“第 1 章”），首页按钮仍是“从第 00 章开始”（FR-18 的文案）。`ChapterSubtitle` 和 `chapter-0X.svg` 删除。

### 3.3 网格、间距、圆角、阴影、图标

- **断点**两档：手机 <720px；平板 720–959px；桌面 ≥960px。v2.2 的 1100px 取消（组件里写 `min-width: 720px` / `960px`）。
- **页面骨架**（首页除外）：顶栏（全宽）下面是两栏：侧边栏 | 正文区。侧边栏宽 `--sidebar-width`：平板 256px，桌面 300px；右边 1px `--border`。正文区里正文栏（`--measure` + 左右内边距）**在剩余宽度里居中**。<720px 只有正文区，侧边栏进抽屉。
- 正文栏内边距：手机 24px 16px，平板起 32px 40px。
- 间距刻度不变：`4 8 12 16 24 32 48 64 96`。
- **圆角**收小（文档站的样子）：按钮、搜索下拉、卡片、代码块、提示块 6px（`--radius`）；截图 4px（`--radius-image`）；搜索框是胶囊（`--radius-pill: 999px`，这是唯一的胶囊形，参考站的样子）。`--radius-control`/`--radius-panel` 合并成 `--radius`。
- 不用阴影表现层级，只有浮层（抽屉、搜索下拉、看大图）用 `--overlay-shadow`。
- 图标仍全部自画：内联 SVG、1.5px 线宽、24px 网格；v3 新增“搜索”（放大镜）和“展开/收起”小箭头（侧边栏章名旁，6px 的实心三角，旋转 90° 表示展开）。联系方式仍用 Simple Icons 的单色路径（FR-23）。

## 4. 页面结构

网站地图和路线不变（五章、两个分叉点，`src/content/route.yaml`）；合并清单定下后，合并页就是普通步骤页，多几个 h2 小节（FR-05、Q-18）。

### 4.0 顶栏和页脚（首页以外的所有页面）

```
桌面 / 平板（≥720px）
┌──────────────────────────────────────────────────────────────────────────────────┐
│ [Re: 标记] Re:从零开始订阅 claude [小形象]   (🔍 搜索       )  [☾]          ⌂ X b 抖 │ 56px，不固定
├──────────────────────────────────────────────────────────────────────────────────┤ 1px --border

手机（<720px，360px 预算见下）
┌────────────────────────────────────────┐
│ [☰] [Re:][小形象]          [🔍] [☾] [联系] │
├────────────────────────────────────────┤
```

- 高 56px，`--bg` 底，下沿 1px `--border`，**随页面滚走**（作者没选固定顶栏）。左右内边距：平板起 24px，手机 12px。
- **左**：手机先是“目录”按钮（菜单图标，44×44，`aria-label="目录"`，打开抽屉）。然后是 logo 的“Re:”标记（高 28px）+ 站名（18px 600 `--text`，<480px 隐藏）+ **小形象**（D6、D7：原尺寸，手机每格 1px 即 24×16，平板起 36×24；不改色、不放大；底边和站名基线对齐，`aria-hidden`）。标记、站名整块链接到首页；小形象不在链接里、不可点。
- **右**，依次（间距 20px，手机 4px）：
  1. **搜索**（FR-24，§4.8）：平板 140px、桌面 180px 宽的胶囊输入框，左侧放大镜，占位文字“搜索”；聚焦时桌面加宽到 220px（不推动其他元素，向左长）。手机只显示 44×44 的放大镜按钮。
  2. **昼夜切换**（用户 2026-10-22 决定，取代原定的视图切换“操作”“原理”，§4.3）：44×44 图标按钮（浅色时月亮、深色时太阳，1.5px 线、`--text-muted`，悬停 `--text`），可访问名称“深色模式”、`aria-pressed`；所有有顶栏的页面都有，没有 JS 时隐藏。
  3. **联系方式**（FR-23）：≥720px 四个 20px 单色图标（`--text-muted`，悬停 `--text`，可点 44×44）；<720px 收成“联系”文字按钮，点开是 `--surface` 底、1px `--border`、6px 圆角的下拉列表，每行图标 + 平台名。
- **360px 预算**（需求 Q-17）：左右内边距 12×2 + 目录 44 + 标记 28 + 间距 6 + 小形象 24 + 搜索 44 + 昼夜切换 44（原定视图切换约 92）+ 联系（约 46）+ 间距 4×3 ≈ 272px，在 360px 内放得下，余约 88px。实现后由 AC-28 的“360 下无横向滚动”和 AC-26 截图核对；万一实测放不下，按需求 Q-17 先提议把小形象收进抽屉，再问作者，不自行删减。
- **页脚**：正文区最下面（翻页之后 48px），一条 1px `--border` 线，下面一行 13px `--text-faint`：“本站是个人教程，与 Anthropic 无关。”，左对齐于正文栏。首页的页脚居中。

### 4.8 站内搜索（FR-24、架构 §13.2）


- **输入框**：胶囊形，高 36px，1px `--control-border`（≥3:1 的控件边界），左内边距 32px 放 16px 放大镜（`--text-faint`），14px 文字；聚焦时边框 `--accent` + 焦点环。`<input type="search" role="combobox" aria-expanded aria-controls aria-autocomplete="list">`，`<label>` 视觉隐藏“搜索页面和小标题”。
- **下拉**：`role="listbox"`，`--surface` 底、1px `--border`、6px 圆角、`--overlay-shadow`，内边距 6px，最高 `min(70vh, 480px)` 可滚动；桌面和平板宽 360px、右缘对齐输入框右缘，手机占满视口宽度、贴着顶栏下沿。每条结果是一个 `role="option"`（内含链接），内边距 8px 12px、6px 圆角：第一行页面标题（15px 600 `--text`），匹配到小标题时第二行“› 小标题”（14px `--text-muted`）；匹配到的文字加粗（不改色）。键盘选中或悬停的一条：`--accent-soft` 底，标题 `--accent`，`aria-selected`。
- **没有结果**：一行 14px `--text-muted` 的“没有找到”（`aria-live="polite"` 播报）。输入为空时不显示下拉。
- **键盘**：上下键移动、回车打开、Esc 先清空再关闭；Tab 离开时关闭。手机上点放大镜后输入框盖住整条顶栏（左边一个“←”关闭按钮，44×44），自动聚焦；关闭后焦点回到放大镜按钮。
- 打开结果的规则见 FR-24 和架构 §13.4（小节只在另一视图时先切视图）。
- 没有 JS 时整个搜索控件不输出可见内容（`hidden`，脚本显示）。

## 5. 交互、反馈与可访问性

**动效**：只有三处过渡，其余直接切换。

| 场景 | 表现 |
| --- | --- |
| 目录抽屉（<720px） | 从左侧滑入 200ms 减速，遮罩淡入；关闭 150ms（沿用 `@starting-style` 方案） |
| 看大图 | 淡入 150ms |
| 桌面搜索框聚焦加宽 | 宽度过渡 150ms |
| 侧边栏章的展开/收起 | 没有动画（`<details>` 直接开合），小三角直接旋转 |
| 翻页、视图切换、搜索下拉 | 没有动画 |
| 链接悬停 | 正文链接下划线 1px → 2px；导航链接变 `--accent` 或加下划线 |
| 按钮按下 | 下移 1px |

- `prefers-reduced-motion` 时去掉所有过渡和位移。
- 原生元素：`<a>`、`<button>`、`<dialog>`、`<details>`；页面开头有“跳到正文”（落在 h1 前）。焦点环 2px `--focus`、间隔 2px，不能去掉。可点区域 ≥44×44（顶栏按钮、翻页、跳过、侧边栏项在手机抽屉里上下内边距加到 10px）。
- 读屏：眉题读 `[data-route-progress]`；小形象、装饰图标 `aria-hidden`；固定字形 `404` 有文字替代；侧边栏是 `<nav aria-label="目录">`，小节列表是当前项的子列表；搜索按 ARIA combobox 模式。
- 隐藏的那版正文 `display: none`（ADR-0004）；按 `data-view` 隐藏的那份小节列表同样 `display: none`。
- **没有 JS 时**：页面可读；导航是构建时写好的；视图固定操作；视图切换和搜索隐藏；≥720px 侧边栏是静态 HTML，`<details>` 照样能开合；<720px 的“目录”链到首页目录；跳转页靠 meta refresh 和链接（ADR-0006）。
- 本机存储不可用时不报错，功能照常（沿用）。

**三种宽度保持同一气质**：同一套白底、细线、纯文字标题和文字翻页；变化只有：<720px 侧边栏进抽屉、搜索收成图标、联系方式收成“联系”；侧边栏宽度在平板和桌面不同；小形象手机上是平板起的 2/3 大。
