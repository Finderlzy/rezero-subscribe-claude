# SSH 提示 Permission denied？

输完 root 密码回车，屏幕上出现 `Permission denied, please try again.`，接着又让你输 `password:`。意思是服务器不认这个密码，不让你进。

最常见的原因是密码输错了。输密码的时候屏幕上什么都不显示，多一个空格、少一个字符都看不出来。先仔细地再输一两次，还是不行的话，按下面的顺序一个一个试：

1. **重置密码，重新连。** 在商家后台把 root 密码改成一个新的，然后关掉现在的命令行窗口，新开一个，重新 `ssh root@你的服务器IP`，输入新密码。
2. **重启电脑**，再重新连一次。
3. **不用 SSH，从商家后台进服务器。** 商家后台一般有一个“登录控制器”（有的叫“控制台”或者“VNC”），点进去就是这台服务器的命令行，和 SSH 连上之后是一样的。在里面用 root 和密码登录，直接把脚本的命令粘贴进去运行就行。最后打印的节点链接复制不出来的话，手机可以直接扫下面的二维码。
4. **申请退款。** 上面都试过还是不行，就找商家退款。还想用这个方案的话，可以再买一台。
