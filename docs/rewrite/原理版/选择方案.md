# 选择方案

选之前可以先看看各家商家的 IP 实测：[[IP 质量实测合集]]。

三个方案的目的都一样：让 claude 看到一个静态住宅 IP，而且只有你自己在用。区别在于怎么实现，选一个，点进去照着做就行。

**方案一：普通服务器 + 白嫖ISP（我用的）**

买一台普通的海外服务器，把它变成节点；再在节点外面套一层免费的 ISP 代理，访问 claude 时走 ISP 的出口。

第一步先白嫖 ISP，看一下质量怎么样，再决定要不要继续走这个方案。

1. [[一、白嫖 ISP]]
2. [[二、购买服务器]]
3. [[三、把服务器变成节点]]
4. [[四、购买 ISP 代理]]
5. [[五、安装面板]]（可选）

**方案二：住宅 IP 服务器**

直接买一台自带住宅 IP 的服务器，把它变成节点。服务器自己的出口就是住宅 IP，不用再套一层。

- [[方案二：住宅 IP 服务器]]

**方案三：直接买住宅节点**

不碰服务器，直接买现成的住宅节点，导入代理软件就能用。

- [[方案三：直接买住宅节点]]

**不管选哪个方案，最后都要 [[导入代理软件]]，再 [[测 IP 质量]]。**
