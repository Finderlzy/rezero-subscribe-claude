# iPhone：买礼品卡充值

美区 Apple ID 有了，但里面没有钱。我们又不能绑国内的卡，那钱从哪儿来？答案是**礼品卡**。

礼品卡就像一张充值卡：你花钱买下一串号码，把号码兑换到 Apple ID 里，余额就到账了。我是在 pockyt shop 上用支付宝买的，这样支付宝只出现在“买礼品卡”这一步，不会出现在 claude 的订阅里。

买的时候有几点讲究：

- **先小额，再慢慢加**。先买 2 美元，确认能到账，再买 5 美元，一点一点增加。万一渠道有问题，损失也小。
- **不要买来路不明的便宜卡**。便宜得离谱的卡可能是“黑卡”，兑换之后 Apple ID 可能被锁。
- **余额要比订阅价格多一点**。以 claude app 里显示的价格为准，app 内价格可能和网页版不一样，再加上可能的销售税，所以多充一点。

**操作**

1. 打开手机浏览器，搜索 [pockyt shop](https://shop.pockyt.io)，认准网址是 shop.pockyt.io。

![[订阅claude-pockyt-1-搜索.jpg|262]]
![[订阅claude-pockyt-2-搜索结果.jpg|262]]

2. 点左上角“游客”，进入登录页。

![[订阅claude-pockyt-3-游客.jpg|262]]
![[微信图片_20261007133655_1_2.jpg|262]]

3. 在登录页的“其他登录方式”里选择支付宝，跳转到支付宝里授权登录。
4. 在“美国”分类下选择“App Store & iTunes”，输入面额购买。**先买 2 美元**，确认到账再买 5 美元，一点一点增加，不要一下子就买 20 美元。显示“缺货”的话，等页面上写的恢复时间再来买。

![[订阅claude-pockyt-5-登录后首页.jpg|262]]
![[订阅claude-pockyt-6-选择礼品卡.jpg|262]]
![[订阅claude-pockyt-7-输入面额.jpg|262]]

5. 在“订单”里复制礼品卡号码。回到 App Store → 右上角头像 →“兑换代码”，填入号码，余额就充进美区 Apple ID 了。

![[订阅claude-兑换-1-礼品卡号码.jpg|262]]
![[订阅claude-兑换-2-兑换代码.jpg|262]]

6. **余额要比 claude app 里显示的订阅价格多一点。**

**也可以从别的靠谱的渠道买**，但不要买来路不明的便宜卡。
