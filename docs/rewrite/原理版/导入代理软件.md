# 导入代理软件

节点准备好之后，就可以把它导入代理软件了。那么代理软件又是做什么的呢？这里要涉及到一个东西：**我国的防火墙**。

前面讲过，claude 会看请求来自哪个 IP，这是我们要过的一道关。其实在这之前还有一道关，就是防火墙。我对防火墙了解得也不多，这里只讲用得上的部分。

防火墙守在国内网络通往海外的出口上。你的请求只要是发往海外的，都要从它这里过。它会看你要去哪儿、发的是什么，不让过的就拦下来，所以你在国内直接打不开 Google、YouTube。

我们的请求要先发到海外的节点，也得从防火墙这里过。如果就这么直接发过去，防火墙一眼就能看出“这是在通过代理访问外网”，请求会被拦下来，节点也可能被封掉。

代理软件就是来解决这个问题的。它装在你的电脑和手机上，你发出的请求先交给它。它把请求加密，再伪装成访问一个普通的大网站，然后发给节点。防火墙看到的只是一次普通的上网，看不出你真正要去哪儿，就放过去了。节点收到之后，拆开伪装，再替你把请求发给 claude。

导入的节点链接里，写着节点在哪儿、怎么加密和伪装。这就是为什么说节点链接就像钥匙，不能发给别人。

那请求是怎么交到代理软件手上的呢？代理软件一般有两种接法：系统代理和 tun 模式。

**系统代理**是在系统设置里登记一句“上网请先找代理软件”。会读这条设置的软件，就自己把请求交给代理软件。问题就出在“自己交”：软件是主动走的代理，所以它是知道你在走代理的，像 claude code 就能看出来。而且不读这条设置的软件、系统自己发出的 DNS 请求，干脆就不走代理，直接用国内网络连出去了。

**tun 模式**是在系统里虚拟出一张网卡，整台电脑的流量都从这张网卡过，被送进节点。软件还是像平常一样上网，根本不知道自己走了代理；不管它读不读系统代理的设置，都逃不掉。

所以，**使用代理软件时，打开 tun 模式就可以，不要用“自动配置系统代理”之类的选项。**

还有一件事：用方案一、二的，脚本给了你两个节点，主节点和备用节点。它们有什么区别呢？

区别在**协议**。协议就是代理软件和节点之间约定好的“说话方式”：怎么加密、怎么伪装。两边说的是同一种话，才能对上。

- **主节点：VLESS + Reality**。它伪装得很像：防火墙去看，看到的是你在访问一个真实存在的大网站，脚本装的时候就挑好了是哪一个。它走的是 TCP，稳定，平时就用它。
- **备用节点：Hysteria2**。它走的是 UDP，网络不好、晚高峰的时候往往更快。但有些地方的网络会限制 UDP，所以它只当备用：主节点连不上或者很慢的时候，再换它。

两个节点出口用的是同一台服务器（方案一访问 claude 时还都会转交同一个 ISP），所以在两个节点之间切换，claude 看到的 IP 是一样的，不算“换节点”。

用 claude 的时候，还要**固定用这一个节点，不要换来换去**。一会儿美国、一会儿日本，本身就很可疑。

**电脑：v2rayN**

1. 从 GitHub 下载 [v2rayN](https://github.com/2dust/v2rayN/releases)，选和你的系统对应的版本，解压。
2. 右键 v2rayN → **以管理员身份运行**。tun 模式要虚拟出一张网卡，需要管理员权限。
3. 复制节点链接，在 v2rayN 里：配置项 → 从剪贴板导入。
   - 方案一、二：节点是运行脚本最后打印的那两个，**通过剪贴板导入**，不要截图发来发去。
   - 方案三：复制商家给的订阅链接，同样从剪贴板导入。
4. 选中主节点，设为当前使用的节点。
5. 主界面底部：系统代理选“清除系统代理”，打开“启用 Tun”。
6. 确认 claude 走代理：不管用“规则”还是“全局”模式，claude 相关的域名都不能直连。不放心的话，用 claude 时直接开全局。

**电脑：Clash Verge**

1. 从 GitHub 下载 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)，安装。
2. 导入节点：
   - 方案一、二：Clash Verge 导入不了 `vless://`、`hysteria2://` 这种分享链接。在服务器上运行 `cat /root/clash.yaml`，复制全部内容，在 Clash Verge 里新建一个本地配置粘贴进去保存。两个节点都在里面，默认选中备用节点 Hysteria2，因为 Clash 的内核连 Reality 节点目前有兼容问题，还在排查。
   - 方案三：复制商家给的订阅链接，在 Clash Verge 里导入订阅。
3. 设置 → 系统设置：打开“虚拟网卡模式”（也就是 tun 模式），第一次打开会提示安装服务模式，照着装上；“系统代理”保持关闭。
4. 和 v2rayN 一样，确认 claude 相关的域名不会直连。
