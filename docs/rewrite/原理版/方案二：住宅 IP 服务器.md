# 方案二：住宅 IP 服务器

先讲一点网络的基础知识。你在浏览器里打开 claude.ai 的时候，你的设备向 claude 的服务器发出了一个**请求**；claude 的服务器收到后，把网页的数据**返回**给你，你才看到了网页。服务器要把数据送回来，就得知道该送到哪儿，所以每个请求上都带着一个“回信地址”，这个地址就是 **IP**。

IP 不只是一个地址，它还能看出两件事：

- **你在哪个国家**。claude 不对中国用户提供服务，一看请求来自中国的 IP，就会制裁你。
- **你是什么人**。每个 IP 都登记在某个组织名下：普通服务器放在机房里，IP 登记在云服务商名下，叫**机房 IP**，普通人不会从机房上网，claude 一看就容易把你当成在用代理；**住宅 IP** 登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在家上网。

所以我们要让 claude 看到的，是一个**海外的住宅 IP**。

方案二的做法，就是直接买一台**住宅服务器**。它是一台放在海外、自带住宅 IP 的服务器，从它这里出去的请求，claude 看到的直接就是住宅 IP。所以你**只需要把这台服务器变成一个节点**就好了：请求先交给它，由它替你发给 claude，claude 看到的就是这台服务器的住宅 IP；claude 返回的数据，再由它转交给你。这台替你收发请求的服务器，就是常说的“**节点**”。

不过要注意一点：**商家说是住宅服务器，分到你手上的不一定真是住宅 IP。** 我自己就买过一台 VoyraCloud 的美国住宅服务器（见 [[实测：VoyraCloud 住宅服务器|它的实测]]），测出来 ipinfo.io 显示 ASN 属于 Bunny Communications，类型是 **Hosting（机房）**，Privacy 为 true；Scamalytics 分数 16，属于低风险，但也识别出在用 VPN/代理。也就是说，我这一台风险分数不高，但分到的是机房 IP，不是住宅 IP。

这只是我一次购买的结果，不代表每次都这样。所以买到之后一定要测，后面“测 IP 质量”那一步会讲怎么测；不是住宅 IP 的话，找商家退款或者换 IP。

**1. 购买住宅服务器**

推荐的购买地址：

- [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M)（我用的是它家的云 VPS，也买过一台它家的住宅服务器，实测结果见上面。）
- [QSU](https://qsu.hk/aff/GAZUQBSL)（我用的是它家子站 proxy.qsu.hk 的住宅代理，主站的住宅服务器**我没有使用过**，有朋友说质量不错，见 [[实测：QSU 住宅服务器|它的实测]]。）
- [丽萨主机](https://lisahost.com/aff.php?aff=15037)（我买过一台它家的美国 9929 双 ISP 住宅 IP VPS，它的产品页面虽然很丑，但是质量还不错：测出来是 ISP 类型，Scamalytics 5 分，见 [[实测：丽萨住宅服务器|它的实测]]。）

按下表选：

| 选项   | 怎么选                                |
| ---- | ---------------------------------- |
| 系统   | **Debian 12**（不要选 Ubuntu）             |
| 配置   | 1 核 CPU、1 GB 内存就够                  |
| 流量   | 每月几百 GB 足够                         |

系统只选 Debian。我自己用的就是 Debian，教程里的命令和脚本都是照着 Debian 来的。Ubuntu 和 Debian 是一家子，长得很像，但有读者反馈，Ubuntu 上有些命令有些许区别，照着教程做容易出岔子，所以干脆统一用 Debian。已经装成别的系统的，在商家后台把系统重装成 Debian 12 就行。

有的商家最高只提供 Debian 11。Debian 11 官方已经停止支持，以后不会再有安全更新，原来的软件源也用不了了。选 Debian 11 也行：脚本会先自动把系统原地升级到 Debian 12 再装节点，多花 5～15 分钟。

买完在商家控制台记下**服务器 IP** 和 **root 密码**。

**2. 把服务器变成节点**

买好之后，连上服务器、把它变成节点，这两件事和方案一完全一样，照着 [[四、把服务器变成节点]] 做就行。

只有一处不一样：脚本问住宅代理 IP 时，直接回车跳过。那是给方案一的普通服务器套 ISP 用的，你的服务器本身就是住宅 IP，不用再套一层。做完之后，**不要点那一页的“下一步”**，直接去 [[导入代理软件]]。
