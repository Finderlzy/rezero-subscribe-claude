# iPhone：在 App Store 登录

iPhone 上其实有两个地方登录 Apple ID：“设置”里的，和“App Store”里的。“设置”里的是 iCloud 账号，管的是照片、通讯录这些；App Store 里的账号只管买东西、下载 app。两边可以不是同一个账号。所以我们只在 **App Store** 里换成美区 Apple ID，“设置”里的还是你原来的账号，照片、通讯录都不受影响。

登录之后还要做几件事，每一件都有原因：

- **账单寄送地址填免税州**。美区会按账单地址所在的州收销售税。填免税州就不会多扣钱；不是免税州的话，余额刚好等于订阅价格时，会因为加了税不够扣，导致付款失败。
- **地址要真实存在、格式正确**，但不一定是你所在的地址，网上搜“免税州地址”都能找到。
- **付款方式保持“无”**。我们是用礼品卡充的余额付钱，不需要绑卡。
- **允许 App 内购买**。这是我遇到“购买未完成”时，Apple 客服让我检查的地方，最好提前设置好。

**操作**

1. 打开 **App Store（不是“设置”）** → 右上角头像 → 拉到最底部，退出原账号，登录美区 Apple ID。“设置”里的账号可以还是你原来的账号。
2. 配置**账单寄送地址**，**付款方式不要动**，保持“无”：
   1. 右上角头像 → 你的名字 →“账单寄送地址”。这一页的“付款方式”应该显示“无”。

![[订阅claude-AppleStore-1-账户设置.jpg|262]]

   2. 跳到“添加付款方式”页面，不用填。第一次进入时它可能要求把付款方式也填了才能保存，同样不用管，直接返回。

![[订阅claude-AppleStore-2-添加付款方式.jpg|262]]

   3. 返回后进入“管理付款方式”，点下面的“账单寄送地址”→ 右上角“编辑”，填一个**免税州的真实地址**（比如俄勒冈州），保存。

![[订阅claude-AppleStore-3-管理付款方式.jpg|262]]
![[订阅claude-AppleStore-4-账单寄送地址.jpg|262]]

3. 搜 Claude，认准开发者是 Anthropic，下载。
4. 设置 → 屏幕使用时间 → 内容与隐私访问限制 → iTunes 与 App Store 购买项目 → App 内购买项目 → 选“**允许**”。
