# iPhone：注册美区 Apple ID

Apple ID 也是分地区的。你在国内注册的 Apple ID 是国区的，App Store 里的价格、能下载的 app、能用的付款方式，都是国区的那一套。要用美区的礼品卡、在美区 App Store 付款，就得有一个**美区 Apple ID**。

已经有一个正常使用的美区 Apple ID 的，跳过这一页。

**操作**

1. 用浏览器打开 appleid.apple.com，手机、电脑都可以（下面是手机的截图）。

![[订阅claude-AppleID-1-打开网址.jpg|262]]

2. 点右上角的箭头展开菜单，选“创建你的 Apple 账户”。

![[订阅claude-AppleID-2-创建账户.jpg|262]]

3. 国家/地区选“**美国**”；姓名可以填拼音；生日要满 18 岁；邮箱用没注册过 Apple ID 的 Gmail；手机号可以用 +86。

![[订阅claude-AppleID-3-选择美国.jpg|262]]

4. 完成邮箱和手机验证。重新登录一次，确认地区是美国。**付款方式不用填。**
