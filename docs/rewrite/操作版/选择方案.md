# 选择方案

三个方案选一个，点进去照着做。选之前可以先看看各家商家的 IP 实测：[[IP 质量实测合集]]。

**方案一：普通服务器 + 白嫖ISP（我用的）**

买一台普通的海外服务器做节点，访问 claude 时走免费的 ISP 代理。先白嫖 ISP、测过质量，再决定要不要继续走这个方案。

1. [[一、白嫖 ISP]]
2. [[二、购买服务器]]
3. [[三、购买 ISP 代理]]
4. [[四、把服务器变成节点]]
5. [[五、打开面板]]（可选）

**方案二：住宅 IP 服务器**

直接买一台自带住宅 IP 的服务器做节点。

- [[方案二：住宅 IP 服务器]]

**方案三：直接买住宅节点**

不碰服务器，直接买现成的住宅节点。

- [[方案三：直接买住宅节点]]

**不管选哪个方案，最后都要 [[导入代理软件]]，再 [[测 IP 质量]]。**
