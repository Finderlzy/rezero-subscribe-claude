# 三、购买 ISP 代理

第一步白嫖到的 ISP 质量不错的话，这一步不用买，直接去 [[四、把服务器变成节点]]。

白嫖到的 ISP 质量不好的话，推荐买 [Decodo](https://decodo.com/)（见 [[实测：Decodo ISP|它的实测]]），它在 Proxyway 2026 年的 ISP 代理测试里排第一，就是贵一些。买的时候选 **SOCKS5** 协议，脚本只支持 SOCKS5。
