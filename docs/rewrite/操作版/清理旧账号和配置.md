# 清理旧账号和配置

开始之前，先把以前登录过的账号、用过的配置都清掉。要清理的地方有三个：

1. **网页端退出账号**：打开 claude.ai → 左下角头像 → Settings → Account，在“Log out of all devices”这一行点 **Log out**。
![[截图 2026-10-15 13-43-53 1.png]]

2. **清理 Claude Code**：换另一个 Agent，让它清理本机 Claude Code 的一切缓存和配置。
3. **手机 App 退出账号**：手机上装过 claude App 的，也在 App 里退出登录。
