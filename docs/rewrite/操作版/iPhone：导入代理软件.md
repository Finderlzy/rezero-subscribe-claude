# iPhone：导入代理软件

1. 在 App Store 里搜索 **V2Box**，下载。

![[iPhone导入代理-1-下载V2Box.jpg|262]]

2. 复制好节点链接：方案一、二复制主节点（`vless://` 开头）；方案三复制商家给的订阅链接。
3. 打开 V2Box。第一次进入会让你做一个快速设置：上面的界面样式随便选；下面的 Select Default Routing Preset 选 **China**，再点 Get Started。

![[iPhone导入代理-2-选择China.jpg|262]]

4. 进入主页，点下方的“配置”，进入配置页。

![[iPhone导入代理-3-首页.jpg|262]]

5. 点右上角的“＋”，选“从剪贴板导入”就可以了。

![[iPhone导入代理-4-配置页.jpg|262]]

6. 滑动下方的“滑动连接”。第一次会问要不要添加 VPN 配置，选允许。

导入之后，确认 claude 走的是你的节点。和电脑一样，手机上也**固定用这一个节点**，不要换来换去。
