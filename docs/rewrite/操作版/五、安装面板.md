# 五、安装面板

这一步是可选的。节点出问题要排查，或者想自己改设置（比如所有网站都走 ISP）时才用得上，现在可以先跳过。

装面板不会改变节点链接，代理软件里不用重新导入。面板只开在服务器本机，要通过 SSH 隧道打开。

**安装**

TODO：下面的命令用的是还没发布的 v1.3.0，发版后才能用。

1. 用 SSH 连上服务器，方法和 [[三、把服务器变成节点]] 里一样。
2. 粘贴这行命令，回车：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Finderlzy/reality-setup/v1.3.0/install-panel.sh)
```

3. 看到 `===== 面板装好了（3x-ui v3.9.0）=====` 就成功了。下面会打印怎么打开面板，以及用户名和密码，**截图保存**。

**打开面板**

1. 在**自己电脑**的命令行运行（换成你的 IP），输入 root 密码，**窗口不要关**：

```bash
ssh -L 8080:127.0.0.1:8080 root@你的服务器IP
```

2. 浏览器打开 `http://127.0.0.1:8080/访问路径`，用截图里的用户名密码登录。
3. 忘了就在第 1 步的窗口里运行：

```bash
cat /etc/x-ui/install-result.env
```

`XUI_WEB_BASE_PATH` 是访问路径，`XUI_USERNAME`、`XUI_PASSWORD` 是用户名、密码。

在面板里改节点会立刻生效，改坏了节点就连不上。只是排查问题的话，看看就好，不要随手改。

在服务器上运行 `node-selftest` 可以随时重新自测节点。
