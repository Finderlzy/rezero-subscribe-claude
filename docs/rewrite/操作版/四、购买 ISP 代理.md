# 四、购买 ISP 代理

把第一步白嫖到的 ISP 配到节点上。

白嫖到的 ISP 质量不好的话，推荐买 [Decodo](https://decodo.com/)（见 [[实测：Decodo ISP|它的实测]]），它在 Proxyway 2026 年的 ISP 代理测试里排第一，就是贵一些。买的时候选 **SOCKS5** 协议。

1. 用 SSH 连上服务器，方法和 [[三、把服务器变成节点]] 里一样。
2. 粘贴这行命令，回车：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Finderlzy/reality-setup/v1.3.0/add-isp-proxy.sh)
```

3. 依次填第一步记下的住宅代理 IP（是一串域名也直接填）、端口、用户名、密码。
4. 问哪些网站走住宅 IP 时，只让 claude 走就直接回车（选 1），想让所有网站都走就输入 `2` 回车。拿不准就选 1：省 ISP 的流量，其他网站的网速也不受影响。
5. 看到 `===== 住宅 IP 加好了 =====` 就成功了，下面一行会写着哪些网站从哪个住宅 IP 出去。

提示“住宅代理连不上”：去商家后台检查端口、账号密码、IP 白名单（把服务器 IP 加进去）、套餐是否生效，再运行一次命令。这个脚本只支持 **SOCKS5** 协议的代理。

以后想换一个 ISP，或者想改选哪些网站走 ISP，再运行一次同一行命令，重新填、重新选就行。
