# iPhone：在 app 内订阅

**要在 claude 的 iOS app 里订阅，不要在网页上订阅。**

1. 打开 Claude app，用 Google 账号登录你的 claude 账号。
2. 点升级 → 选择方案 → 用 Apple ID 余额付款。
3. 订阅之后，可以在 App Store → 右上角头像 →“订阅”里管理或取消。

如果提示“购买未完成”（Purchase Not Completed）或付款被拒绝，**先别反复重试**，看 [[iPhone：购买未完成]]。
