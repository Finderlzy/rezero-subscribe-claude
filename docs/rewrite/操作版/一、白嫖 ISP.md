# 一、白嫖 ISP

1. 在 [proxy.qsu.hk](https://proxy.qsu.hk/) 注册（IP 质量怎么样，见 [[实测：proxy.qsu.hk 白嫖 ISP|它的实测]]）。注意它和主站 qsu.hk 卖的东西不一样，主站卖的是方案二的住宅服务器（见 [[实测：QSU 住宅服务器|它的实测]]）。
2. 选 **SOCKS5 协议**的套餐，下单时填优惠码 `qiansu998`，就可以免费拿到一个住宅 IP 端口。优惠码随时可能失效，流量额度等以下单页面为准。
3. 在线路详情里记下**住宅 IP、端口、用户名、密码**。这里的“住宅 IP”可能是一串域名，比如 `r52u2gaa.isp201.iisp.asia`，这很正常，照着记下来就行。

**先测一下质量**

每个人白嫖到的 IP 都不一样，别人测出来好，不代表你拿到的也好，一定要自己测。

1. 先关掉电脑上的代理软件，否则测出来的 IP 不对。
2. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
3. 输入下面这行，`用户名`、`密码`、`地址`、`端口` 换成第 3 步记下的：

```bash
curl -x socks5h://用户名:密码@地址:端口 https://ipinfo.io/json
```

4. 返回结果里 `"ip"` 那一行就是出口 IP，把它复制下来。
5. 打开 `https://ipinfo.io/` 加上这个 IP（比如 `https://ipinfo.io/1.2.3.4`），看 AS Type 和 Privacy；再把这个 IP 粘贴到 [scamalytics.com](https://scamalytics.com/) 查风险分。怎么看，见 [[测 IP 质量]]。

连不上的话：

- 密码里有 `@`、`:`、`#` 这类符号，命令会被拆错。可以在商家后台换一个只有字母和数字的密码。
- 商家后台有 IP 白名单的话，把你自己现在的 IP 加进去。

**测出来质量不好**

可以找商家客服换一个 IP，换完再测一次；也可以回到 [[选择方案]]，换别的方案。

还想继续走方案一的，也可以买付费的 ISP，见 [[四、购买 ISP 代理]]。
