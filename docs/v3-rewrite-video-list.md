## 录完后怎么替换

1. 找到对应的 `**视频 XX-X：...**` 占位行。
2. 把占位行换成“引导语 + 视频嵌入”，例如“下面的视频演示整个换区过程：”。平台和站点组件还没定；如果放 B 站/YouTube，需要先把站点的“每页一个视频门面”扩展成正文内可用的视频组件；如果放本地 mp4，需要先定 mp4 的存放位置。
4. 删掉该小节里已经不再需要的过渡文字（如果有）。
