# 方案一：搭建专属住宅代理节点
---

这一章从零开始：先买一台普通的海外云服务器（VPS），再配一个静态住宅 ISP 代理，最后用脚本把服务器变成只属于你的节点。做完之后，你会拿到两条可以直接导入客户端的节点链接：一条 VLESS Reality 主节点，一条 Hysteria2 备用节点。访问 Claude 时，对方看到的是一个住宅 IP。

```text
选购海外 VPS
   ↓
选购住宅 ISP 代理
   ↓
现场检测代理质量
   ↓
SSH 连接服务器，运行一键脚本
   ↓
保存节点链接和面板凭据
```

### 原理：为什么要两层

你可能会问：为什么不直接用海外 VPS，或者直接买住宅代理？

- **普通云服务器（VPS）** 的 IP 登记在机房，属于 Data Center / Hosting 类型。它连接稳定、带宽大、价格便宜，但普通人不会从机房上网；Claude 的风控看到机房 IP，很容易把你当成在用代理。
- **静态住宅 ISP 代理** 的 IP 登记在海外电信运营商名下，在风控眼里就是普通家庭宽带。但住宅流量很贵，而且商家通常只给你一个 SOCKS5 代理端口，直接拿它连 Claude 既慢又不稳定。

所以方案一把两者接起来：

```text
你的设备
   ↓  加密、伪装
海外 VPS
   ↓  只把 Claude 和 ipinfo.io 转给 ISP
住宅 ISP 代理
   ↓
Claude 官方服务器
```

VPS 负责稳定地“连通海外”，ISP 代理负责“最后一跳”，让 Claude 觉得你是一个真实的家庭用户。脚本会自动在服务器上做好分流：只有访问 Anthropic 相关网站和 `ipinfo.io` 时才走昂贵的住宅流量，其他网站仍然从服务器自己的出口出去。这样钱花在刀刃上，看视频、查资料也不会消耗 ISP 的流量。

## 购买海外 VPS
---

VPS 是整个节点的地基。在 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买一台 Debian 12、1 核 CPU、1 GB 内存的云 VPS，机房选美国、日本或新加坡都可以；它一般是机房 IP，不过访问 Claude 时走的是 ISP，所以不用在意它的 IP 质量。买完在商家控制台记下**服务器 IP**和 **root 密码**。

配置怎么选：

| --- | --- | --- |
| 操作系统 | **Debian 12** | 不要选 Ubuntu。 |
| 硬件配置 | 1 核 CPU、1 GB 内存 | 个人代理够用，不需要多花钱。 |

### 为什么只选 Debian

教程里的命令和脚本都是照着 Debian 写的。Ubuntu 和 Debian 很像，但有读者反馈，Ubuntu 上有些命令有细微差别，照着做容易出岔子，所以统一用 Debian；已经装成别的系统的，在商家后台重装成 Debian 12 就行。

有的商家最高只提供 Debian 11。Debian 11 已经停止支持，软件源也用不了了；选 Debian 11 也可以，脚本会先把它原地升级到 Debian 12，再装节点，多花 5～15 分钟。

## 购买静态住宅 ISP 代理
---

ISP 代理是节点的“最后一跳”。在 [Decodo](https://decodo.com/) 或别家买一个 SOCKS5 代理，记下**代理地址**、**端口**、**用户名**和**密码**；地址可能是一串域名，比如 `r52u2gaa.isp201.iisp.asia`，这很正常。

**视频 02-2：购买静态住宅 ISP 代理**

推荐 Decodo，但我自己没有用过；推荐它是因为它在 Proxyway 2026 年的 ISP 代理测试里排第一，价格很贵，贵到已经可以直接买一台住宅 IP 服务器了。你可以把它当作质量参照，再按预算选别家。不管在哪家买，协议都必须是 SOCKS5，脚本只支持 SOCKS5。

### 先测代理质量，再决定用不用

拿到代理之后，不要急着装软件。关掉电脑上的代理软件，打开命令行（Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”），运行下面的命令，把用户名、密码、地址、端口换成你记下的：

```bash
curl -x socks5h://用户名:密码@地址:端口 https://ipinfo.io/json
```

返回的 JSON 里，`"ip"` 那一行就是出口 IP。把它复制下来，打开 `https://ipinfo.io/` 加上这个 IP，比如 `https://ipinfo.io/1.2.3.4`，看 AS Type 和 Privacy；再把这个 IP 粘贴到 [Scamalytics](https://scamalytics.com/) 查风险分。分数越低越好：0～20 属于低风险，20～40 需要留意，50 以上不建议使用；不要用 ping0.cc 查，它会暴露你国内的真实 IP。

**视频 02-3：测 ISP 代理的出口 IP**

| 字段 | 理想结果 | 怎么看 |
| --- | --- | --- |
| AS Type | `isp` | 最关键的一项。`isp` 表示运营商的 IP，可以用；`hosting` 表示机房 IP，建议换；`business` 是企业网络，介于两者之间。 |
| Privacy | `false` | 有没有被识别成 VPN、代理或 Tor。`false` 才对。 |
| Hosted domains | 0 | 这段 IP 上挂了多少网站。机房 IP 常挂着网站，0 比较好。 |

如果连不上，先检查这三件事：密码里有 `@`、`:`、`#` 这类符号，命令行会把地址拆错，可以在商家后台换一个只有字母和数字的密码；商家后台开了 IP 白名单，需要把你当前的本地上网 IP 加进去；套餐还没生效，或者端口填错了。

测出来质量不好，可以找客服换一个 IP，换完再测一次；也可以回到[选择方案](01-整体思路与方案选型.md)，换别的方案。

## SSH 连接服务器
---

服务器在海外，没有屏幕，也没有键盘，我们要用 **SSH** 远程登录它：连上之后，你在自己电脑上敲的命令，会被送到服务器上执行，结果再传回你的屏幕。打开命令行（Windows 按 `Win + R`，输入 `cmd`；Mac 打开“终端”），输入下面的命令，把 `你的服务器IP` 换成真实 IP：

```bash
ssh root@你的服务器IP
```

第一次连接会问 `Are you sure you want to continue connecting (yes/no)?`，输入 `yes` 回车；出现 `password:` 时输入 root 密码，屏幕上不会显示任何字符，这是正常的。当提示符变成 `root@...:~#`，说明已经进入服务器。

**视频 02-4：SSH 连接服务器**

### 如果连不上

提示 `Connection refused`，或者根本没出现 `password:`，说明 SSH 端口不是默认的 22。去商家后台看“端口”一栏，如果写的是别的数字，比如 38221，就在命令里加小写 `-p`：

```bash
ssh -p 38221 root@你的服务器IP
```

提示 `Permission denied, please try again.`，说明服务器不认这个密码。先仔细再输一两次，注意不要多打空格；还是不行的话，在商家后台重置一次 root 密码，关掉当前命令行窗口，新开一个重试；或者直接用商家后台的“控制台 / VNC”登录，效果和 SSH 一样。

## 运行一键脚本
---

登录服务器后，复制下面这行命令，粘贴进去，回车：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Finderlzy/reality-setup/v2.0.0/setup.sh)
```

脚本会安装 Xray 和管理面板，然后把 ISP 代理套到节点上；安装过程中会在终端里问你几个问题。

**视频 02-5：运行一键脚本（方案一）**

| 终端提问 | 怎么填 |
| --- | --- |
| 是否删掉旧的重新装？ | 只有这台服务器装过本脚本或 3x-ui 面板才会问。想重装输入 `y`；否则输入别的，脚本不会动旧数据。 |
| 服务器 IP 是 xxx 吗？ | 和你的服务器 IP 一样就直接回车；不一样就手动输入你 SSH 连接用的 IP。 |
| 住宅代理 IP / 域名 | 填前面记下的 ISP 地址。是一串域名也直接填。 |
| 住宅代理端口、用户名、密码 | 依次填入前面记下的参数。脚本会验证代理能不能连通。 |

输入完成后等 2～5 分钟。期间如果弹出紫色或蓝色的配置窗口，直接回车保持默认即可；如果服务器是 Debian 11，脚本会先升级系统，要多等 5～15 分钟。

### 部署成功的标志

当终端底部出现下面两行，说明节点已经装好了：

```text
节点自测 Reality：成功
节点自测 Hysteria2：成功
```

最后脚本会打印两样东西，都要保存好：**主节点链接**以 `vless://` 开头，平时用这个，忘了可以在服务器上运行 `cat /root/vless.txt` 再看一次；**备用节点链接**以 `hysteria2://` 开头，主节点连不上或很慢时换它，忘了就运行 `cat /root/hy2.txt`。还有面板的登录信息，记下来，后面打开面板要用。

> [!caution] 节点链接就是钥匙
> 节点链接里写着服务器的地址和凭证。脚本会随机生成一个 UUID 作为凭证，只要你不把链接发给别人，别人就拿不到你的节点。不要截图发群，也不要放进公开的仓库。

### 端口和防火墙

如果商家后台有“防火墙”或“安全组”，确认放行了 **TCP 443** 和 **UDP 443**，否则节点在外部连不上。

如果脚本把 Debian 11 升级到了 12，最后会提示你重启。找个方便的时候运行：

```bash
reboot
```

节点会随系统自动启动。

### 如果提示住宅代理连不上

回到商家后台，依次检查：端口、用户名、密码有没有填错；有没有 IP 白名单，有的话把**服务器 IP**加进去；套餐是否已经生效；协议是不是 SOCKS5。改完再运行一次同一行命令。

## 打开面板（可选）
---

面板是一个网页版后台，用来查看节点状态、改节点设置。脚本已经把面板装好了，节点就是在面板里建的；现在用不上的，可以先跳过。

面板能改节点，所以脚本把它**只开在服务器本机**，从外网直接访问是打不开的。要打开它，得用 SSH 打一条隧道：你在自己电脑上访问一个地址，SSH 会把它送到服务器上，就好像你坐在服务器面前。在**自己电脑**的命令行运行下面这行，输入 root 密码，窗口不要关：

```bash
ssh -L 8080:127.0.0.1:8080 root@你的服务器IP
```

**视频 02-6：打开 3x-ui 面板**

浏览器打开 `http://127.0.0.1:8080/访问路径`，用安装完成时打印的用户名和密码登录。如果忘了，在服务器上运行：

```bash
cat /etc/x-ui/install-result.env
```

`XUI_WEB_BASE_PATH` 是访问路径，`XUI_USERNAME` 和 `XUI_PASSWORD` 是用户名和密码。

面板默认的用户名、密码和端口，用这个脚本装出来的人都一样。这不代表别人能登进来：面板只监听服务器本机，要进来必须先通过 SSH 隧道，而打隧道需要你的服务器密码；除非别人知道你的服务器密码，否则进不了面板。

在面板里改节点会立刻生效，改坏了节点就会连不上。只是排查问题的话，看看就好，不要随手改。

### 常见问题

#### 怎么确认这个节点真的只有我一个人在用

自己搭节点，这一点比买现成节点可控得多：

- 节点凭证（UUID）是脚本随机生成的，只有你的链接里有；
- 只要你不分享 `vless://` 或 `hysteria2://` 链接，别人就拿不到这个节点；
- ISP 代理也是你自己买的独立端口。

如果想进一步确认 ISP 是不是独享，可以连续几天测同一个出口 IP，看地址是否一直不变、Scamalytics 分数有没有慢慢变高；买之前也可以直接问商家，是“独享 IP”还是只“独享带宽”。

#### 以后想换一个 ISP

重新运行同一行脚本，填入新的 ISP 参数即可。重装后节点链接会变，代理软件里要删掉旧节点，重新导入。

> [!caution] 重装前先关掉电脑上的代理软件
> 你 SSH 连服务器时，连接本身可能正走在这台服务器的节点上。脚本一删旧节点，SSH 就会断开，出现 `Connection to ... closed by remote host`。所以重装前先关掉代理软件，或者关掉 TUN / 全局模式，再 SSH 连服务器。

#### 节点突然连不上

SSH 连上服务器，运行内置的自测命令：

```bash
node-selftest
```

它会重新检测 Reality 和 Hysteria2 是否正常监听。如果 ISP 那边出了问题，脚本的自测可能会失败；按“住宅代理连不上”的步骤检查，或者找 ISP 商家。
