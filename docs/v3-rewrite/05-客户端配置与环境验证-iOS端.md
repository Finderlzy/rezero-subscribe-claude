# 客户端配置与环境验证：iOS 端
---

iPhone 和 iPad 上的代理比电脑简单一些。iOS 的代理软件以 **VPN** 的方式工作：打开之后，整台手机的流量都要先经过它，所有 App 都逃不掉，相当于系统自带 Tun 模式，不需要另外设置。

这一章要完成三件事：下载代理软件、导入节点、把手机环境调到和节点一致。

```text
准备外区 App Store
   ↓
下载 V2Box
   ↓
导入节点并连接
   ↓
改时区，做连通性测试
   ↓
下载 Gmail
```

## 第一步：准备一个能下载代理软件的 App Store
---

国区 App Store 搜不到代理软件，要下载就得先把 App Store 换到别的国家或地区。

如果你已经有美区或其他外区的 Apple ID，直接在 App Store 登录那个账号下载即可，可以跳过这一节。

如果手头只有国区账号，可以临时把 App Store 换到奥地利。苹果允许账号无卡换区，奥地利支持 **EPS** 付款方式：只要选银行、填地址，不用填卡号。

> [!caution] 换区会取消自动续期订阅
> 换地区时，这个账户里所有自动续期的订阅都会被取消，App Store 会提示你。如果你有正在续期的订阅，先想清楚。下载完代理软件后，可以按同样的步骤把地区改回中国大陆。

1. 打开 App Store，点右上角头像，再点最上面的账户名（下面写着“账户信息、付款方式和设置”），按提示验证面容 ID 或密码。

   ![[iPhone改奥地利-1-Apple账户.jpg|262]]

2. 点“国家/地区”。

   ![[iPhone改奥地利-2-账户设置.jpg|262]]

3. 在下方的搜索框里搜“**奥地利**”，点它。

   ![[iPhone改奥地利-3-搜索奥地利.jpg|262]]

4. 提示“所有自动续期的订阅都将被取消”，点“继续”。

   ![[iPhone改奥地利-4-确认更改.jpg|262]]

5. 条款是德语的，直接点“同意”。

   ![[iPhone改奥地利-5-同意条款.jpg|262]]

6. 添加付款方式：付款方式选 **EPS**，下面的 Bank **必须选 Bank Austria**，不用填卡号。

   ![[iPhone改奥地利-6-选择EPS.jpg|262]]

   ![[iPhone改奥地利-7-选择银行.jpg|262]]

7. 账单寄送地址：PLZ（邮编）填 `1010`；其他写着 Erforderlich（必填）的，比如 Adresse 1、Stadt、Vorname、Nachname，随便填就行。

   ![[iPhone改奥地利-8-填写地址.jpg|262]]

8. 点右上角蓝色的 ✓ 保存。

改好之后，在 App Store 里搜索 **V2Box**，下载安装。V2Box 免费，带一点广告。

![[iPhone导入代理-1-下载V2Box.jpg|262]]

下完可以把 App Store 改回中国大陆：步骤和上面一样，只是在第 3 步搜“中国大陆”。已经下载的 App 不受影响；以后要更新 V2Box 时，可能需要再切回外区。

### 小火箭用不了怎么办

小火箭（Shadowrocket）也能用，但有的群友导入节点后怎么都连不上。脚本装出来的主节点是 VLESS 协议，可能某些版本的小火箭和它配合得不好。

如果遇到这种情况，不用排查，直接换一个代理软件。V2Box 是免费的，本文的步骤也以它为例。

## 第二步：在 V2Box 里导入节点
---

1. 复制节点链接：
   - 方案一、二：复制脚本最后打印的主节点（`vless://` 开头）；
   - 如果你还有别的住宅节点，复制商家给的订阅链接。
2. 打开 V2Box。第一次启动会引导你做快速设置：
   - 上面的界面样式随便选；
   - 下面的 **Select Default Routing Preset** 选 **China**；
   - 点 **Get Started**。

   ![[iPhone导入代理-2-选择China.jpg|262]]

3. 进入主页，点下方的“配置”，进入配置页。

   ![[iPhone导入代理-3-首页.jpg|262]]

4. 点右上角的“＋”，选“从剪贴板导入”。

   ![[iPhone导入代理-4-配置页.jpg|262]]

5. 列表中会出现你的节点，点一下选中它。
6. 回到主页，滑动下方的“滑动连接”。第一次会弹出系统授权，问要不要添加 VPN 配置，点 **允许**，再验证面容 ID 或锁屏密码。

> [!note] 为什么选 China
> 选 China 表示国内网站和应用直连，只有访问海外服务时才走节点。这样平时刷微信、看国内视频不绕路，也节省节点的流量。

连接成功后，手机的所有流量都会经过 V2Box。和电脑一样，**固定用这一个节点**，不要今天这里明天那里。

## 第三步：调整手机环境
---

### 改时区

iOS 的时区有两个开关，**两个都要关**。

1. 设置 → 隐私与安全性 → 定位服务 → 系统服务（滑到最底下）→ 关闭 **设定时区**。
2. 设置 → 通用 → 日期与时间 → 关闭 **自动设置** → 手动选择城市。

只做第 2 步的话，手机可能还会根据定位把时区改回来。

时区选 Claude 支持的地区，比如台湾、新加坡；不确定就选住宅 IP 所在城市的时区。**中国大陆和香港不行。**

### 语言与地区（可选）

设置 → 通用 → 语言与地区。这一项不是必须的，但如果你希望手机看起来更像一个海外用户，可以把“地区”改成和时区一致的地方。

### iCloud 专用代理

如果你开通了 iCloud+，并且打开了“专用代理（Private Relay）”，建议在使用 Claude 期间关掉它：

设置 → 最上方 Apple ID → iCloud → 专用代理 → 关闭。

专用代理可能接管 Safari 的流量，让请求从另一个出口出去，导致你的 IP 频繁变化。不是每个账号都有这个功能，没有就不用管。

## 第四步：验收
---

保持 V2Box 连接，用 Safari 打开：

1. [ipinfo.io](https://ipinfo.io/)，确认页面顶部显示的 IP 是你的节点出口，**AS Type 是 `isp`**，**Privacy 是 `false`**。
2. [ipleak.net](https://ipleak.net/)，确认没有出现国内的 DNS 或 IPv6 地址。

如果几个网站显示的 IP 不一样，先看[日常维护与故障处理](09-日常维护、风控应对与常见故障.md)里的“测出来好几个不同的 IP”。

## 第五步：下载 Gmail
---

1. 确认 V2Box 已经连接。
2. 在 App Store 里搜索 **Gmail**，认准开发者是 Google，下载。

很多 iPhone 自带 Gmail，已经有的就不用再下。
