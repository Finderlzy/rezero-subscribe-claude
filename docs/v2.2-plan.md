## 1. 已定的设计决定

| # | 决定 | 理由 |
| --- | --- | --- |
| D1 | 整体方向换成**精确工具**：白底、细灰线、编号圆圈、黑色主按钮；放弃 v2.1 的纸色底和“说明书”隐喻 | 作者选定；照做的内容（命令、截图）在干净的底上最清楚 |
| D2 | 配色：**纯白 + 墨黑 + 葡萄紫**。紫色只用在链接、当前位置、页头色带的眉题和“已选”状态上 | 作者选定；紫色来自 logo，降低饱和度后不再大片抢眼 |
| D3 | 标题字重 **600**（不用 700/800）；正文 400 | 苹果设备上是苹方中粗体，轻而利落。Windows 的微软雅黑没有 500，写 500 会退回常规体，所以用 600 |
| D4 | 每个页面顶部一条**浅紫页头色带**，里面放眉题和 h1（借鉴 Josh Comeau 站点的页头，但用直边、不用天蓝、不加云朵或波浪） | 一进页面就知道“这是哪一步”；替代页边大号编号 |
| D5 | 正文放大一号，行距放宽；提示框改成浅色底、带小标签 | 借鉴 Josh Comeau 站点的阅读舒适度 |
| D6 | 使用 Claude Code 的**官方像素小形象**：保持官方橙色，只用标准姿态，不改色、不放大、不改画、不配台词；趴在页头色带的下沿；页脚注明非官方 | 作者坚持使用官方形象；Agent 不推荐，已记录分歧（§7）。按作者决定执行，并把负面影响降到最低 |
| D7 | 橙色**只属于小形象**，不出现在任何按钮、链接、色块上 | 橙紫分工，避免两个强调色互相抢 |
| D8 | 桌面（≥1100px）**左侧目录常驻**；平板和手机仍是抽屉 | 作者要求（修改 1） |
| D9 | 不做右侧“本页内容”目录 | 左侧已有常驻目录，左右两套导航会互相抢；步骤页的小标题也少 |
| D10 | 步骤页**去掉页边大号步骤编号**，章和步一律写成文字：“第 1 章 · 准备节点和住宅 IP · 第 2 步，共 10 步” | 作者反馈章节号和步骤号都是“0X”，看起来一样（修改 3） |
| D11 | 新增“附录”：常见问题 + IP 质量实测合集；后记的下一步进入附录，不再回首页 | 作者要求（修改 4） |
| D12 | 常见问题**一条一页**，常见问题首页是条目目录 | 作者要求（修改 5） |

## 7. 被否决的想法（写进 design.md）

| 想法 | 否决原因 |
| --- | --- |
| 方向 A“温纸编辑”（宋体标题 + 色块卡片） | 作者选了 B |
| 方向 C“书页”（全衬线、居中） | 命令和截图与书卷气冲突，手机上大段宋体难读 |
| 照搬 Claude 官网的陶土橙、衬线和米色 | 本站讲的是订阅 Claude，像官方页面会被怀疑是仿冒，伤害“靠谱” |
| 天蓝页头、云朵、波浪边、卡通插画（Josh Comeau 的标志元素） | 一眼会被认出是模仿；蓝紫是两个强调色；太活泼，和本站的严肃话题不配 |
| 二次元风格的 Claude 人形形象、番剧角色 | 官方或仿冒的嫌疑；番剧角色不是本站的 |
| 小形象趴在“下一步”按钮上 | 手机上吸底底栏会让它一直在视线里，分散注意力 |
| 小形象改成紫色或放大 | 改色看起来像仿品，放大后像品牌代言 |
| 右侧“本页内容”目录 | 和常驻左侧目录形成两套导航 |
| **保留的分歧**：使用官方像素形象 | Agent 仍不推荐（同样有官方或仿冒的嫌疑），作者坚持，按 D6/D7 的方式降低影响 |
