# 迁移核对清单（v3，V11 现状）

本文件记录从作者重写稿导入站点时的核对口径和结果。v1/v2 的逐页核对表是历史，已随作者 2026-10-22 的新稿失效，原文见 git 历史（2026-10-23 之前的版本）。

## 范围

- **内容源**：`docs/v3-rewrite/` 的 11 个文件，一章一页、只有一版正文；`docs/v3-rewrite/reference/` 的 IP 质量实测合集和 6 篇实测。
- **页面**：11 个页面 + 7 个参考页；首页、404、跳转页、搜索索引由构建生成，不在逐页比对范围。
- **页面标识和旧网址**：以需求 §5.2 和实施计划 §3.1 为准；`route.yaml` 的 `moved:` 共 47 条（37 条旧页面含 6 条手机分流、8 条旧常见问题路径、旧 `faq` 目录，以及 2026-10-19 删掉的 `plan1-free-isp`）。`/ip-tests/` 和 6 篇实测保留原网址，不写 `moved:`。
- **单一正文**：不再有原理版/操作版两种视图，`[page].astro` 只渲染一份正文；跳转页、搜索和侧边栏都不按视图分支。

## 导入和校验

- **导入**（ADR-0005）：`node scripts/import-rewrite.mjs` 从 `docs/v3-rewrite/` 按标题导入 11 页和参考页，把相对 Markdown 链接转成站内链接，复制被引用的截图和说明图；连跑两次第二次应无改动。正文不手改；要改内容就改重写稿再导入。
- **标题**：正文第一行 `# 标题` 必须存在，全站唯一；页面标题、导航标题和搜索索引都从这里取。
- **链接**：`[[页面]]`、`[[页面#小节]]`、同页 `#小节`、相对 Markdown 链接都要解析到存在的页面和标题；缺页、缺锚点、缺图时构建失败。
- **路线图**：5 章、2 个分叉点、11 页；每条路线从 `preface` 到 `afterword` 无环、无断链。
- **跳转表**：目标页存在、小节存在、旧标识不和新页面/参考页同址、不串联、`choice` 的选项和分叉点一致；`faq` 只能作为旧网址，不能用作页面标识。
- **参考页**：`TOC_REFERENCES` 只列 `ip-tests`；`ip-tests` 和 6 篇实测都进目录、搜索和 sitemap。
- **内容提示**：构建结束列出“作者待补”；当前只剩 `ip-tests/qsu-residential` 1 处，不阻塞构建。

## 截图和敏感信息

- 截图只放 `src/assets/screenshots/`，说明图只放 `src/assets/diagrams/`，都由导入脚本从 `docs/v3-rewrite/附件/` 复制；不手改生成物。
- 入库前逐张核对打码：不能露出真实服务器 IP、节点链接、面板账号、完整邮箱/姓名/地址/电话。v3 新稿引用的 40 张图片已在导入时复查；保留的 7 个实测页图片沿用 2026-10-19 的核对结果。
- 正文里只允许示例 IP（如 `203.0.113.x` 之类）和公共 DNS；不提交凭据、真实 IP、节点链接、面板账号。发现未打码的截图先不入库，交作者处理。
