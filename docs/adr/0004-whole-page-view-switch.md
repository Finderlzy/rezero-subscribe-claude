# 两版正文同页静态输出，用 CSS 整页切换视图

- 状态：accepted（2026-10-15），取代 [ADR-0003](0003-principle-content-as-why-callouts.md)

v2.0 的原理视图是另一篇完整的文章（作者重写的原理版），不再是操作正文加几个展开块（需求 §0、FR-30）。切换必须在同一个 URL 上换整页正文，滚回顶部，并且记住视图（FR-31）。我们在构建时把原理版和操作版的正文都渲染进同一个页面，分别包在 `data-body="principle"` 和 `data-body="operation"` 里，由 `<html data-view>` 决定显示哪一个；首次绘制前的内联脚本按本机保存的视图设置 `data-view`，没有 JS 时固定显示操作版。

## Considered Options

- **两个 URL（`/<id>/` 和 `/<id>/principle/`）**：违反“同一 URL”的要求，分享出去的链接会把对方锁在某个视图里，URL 数量也翻倍（ADR-0002 要锁定 URL）。
- **只输出一版，切换时用 `fetch` 取另一版**：要多一套片段产物，没有 JS 时看不到原理版，弱网下切换会等待；为省几 KB 文字不值得。
- **继续用原理块（ADR-0003）**：重写稿的两版不是“操作 + 补充段落”的关系，没法拆成块。

## Consequences

- 页面里有两份正文：操作版的标题 id 加 `op-` 前缀，避免重复 id；隐藏的那份用 `display: none`，屏幕阅读器、页内查找和懒加载图片都会跳过它。页面体积约为一版的两倍，正文是纯文字，可以接受。
- 代码复制、看大图等脚本要对两份正文都生效（按选择器统一挂载即可）。
- 原理独有步骤和还没写操作版的页面只输出原理版，操作视图下显示提示（FR-21、FR-30）。
