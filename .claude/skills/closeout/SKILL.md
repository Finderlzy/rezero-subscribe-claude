# Closeout

一个里程碑的所有任务都 implement 完之后跑一次。

## 1. 定位里程碑

用户指定了就用它；否则读地图 `.scratch/<项目>/map.md` 的 `## Milestones`，取第一个未勾选的。找到它对应的 `.scratch/<里程碑>/`。

## 2. 核对任务

逐个读 `issues/` 下的文件：`Status:` 为 `done`，验收条件全部勾选。有没做完的就列出来并停下，问用户是补做还是移出本里程碑。

## 3. 跑完整检查

跑项目已有的完整测试、类型检查和 lint。失败就停下报告，不在这一步修。

## 4. 合并分支

本里程碑有在 worktree 或其他分支上的工作时，列出分支和未合并的提交，经用户确认后合并回主分支，再清理对应的 worktree。

## 5. 落盘

- `spec.md` 顶部加 `Status: done`。
- 勾选地图 `## Milestones` 里的这一项。
- 两处改动一起提交。

## 6. 交还

告诉用户：本里程碑完成了什么、下一个里程碑是什么。建议跑 `/retro`。
