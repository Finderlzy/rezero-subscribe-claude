## 整体思路与方案选型

对应页面：https://re0claude.us.ci/overview/

### 整套方案大概要花多少钱

订阅本身每月 20 美元。网络这边，方案二是一台住宅 IP 服务器，我买的每月 9 美元左右；方案一是一台普通 VPS 加一个住宅 ISP 代理，ISP 代理往往比 VPS 贵，两个加起来和方案二差不多。再算上礼品卡的汇率、手续费，以及买错、换机这类试错成本，第一个月准备 30～50 美元比较稳妥。想省钱的话，先用免费号把前面的步骤走完，确认自己能撑下来，再付订阅费。

### 先走方案一，以后想换成方案二可以吗

可以，但节点那一段要从头再做一遍：换一台自带住宅 IP 的服务器，重新跑脚本，拿到新的节点链接，导进客户端。账号不用重新注册——Claude 账号是用 Google 账号注册的，和节点无关。不过出口 IP 会变，换完之后按日常维护那章的“保持出口 IP 稳定”做：先退出登录，隔一会儿再从新出口登录，新 IP 也按第 2 章的标准重新测一遍。

### 买别人做好的账号行不行

不建议。账号不是从零注册的，你不知道它之前的 IP、设备和使用记录，也不知道原来的主人还会不会登；接手之后环境突然一变，反而更容易被判成有问题。这份教程是从注册开始自己走一遍，麻烦，但每一项都在你自己手里。

## 方案一：搭建专属住宅代理节点

对应页面：https://re0claude.us.ci/plan1/

### 很便宜的香港小鸡，标着“住宅”或“双 ISP”，能不能买

按标准测，不要只看商家标题。这类低价的“住宅”很多是把机房骨干网包装成原生住宅，测出来 AS Type 是 `hosting`、Privacy 是 `true`，用上去等于给自己加风险。买之前按上面“先测代理质量，再决定用不用”那张表对一遍；便宜得离谱又拿不出 ASN 和类型证明的，直接跳过。

### 怎么确认这个节点真的只有我一个人在用

自己搭节点，这一点比买现成节点可控得多：

- 节点凭证（UUID）是脚本随机生成的，只有你的链接里有；
- 只要你不分享 `vless://` 或 `hysteria2://` 链接，别人就拿不到这个节点；
- ISP 代理也是你自己买的独立端口。

如果想进一步确认 ISP 是不是独享，可以连续几天测同一个出口 IP，看地址是否一直不变、Scamalytics 分数有没有慢慢变高；买之前也可以直接问商家，是“独享 IP”还是只“独享带宽”。

说实话，**没法百分百确认**，只能这样间接看，所以建议先买一个月试试。

### 以后想换一个 ISP

重新运行同一行脚本，填入新的 ISP 参数即可。重装后节点链接会变，代理软件里要删掉旧节点，重新导入。

> [!caution] 重装前先关掉电脑上的代理软件
> 你 SSH 连服务器时，连接本身可能正走在这台服务器的节点上。脚本一删旧节点，SSH 就会断开，出现 `Connection to ... closed by remote host`。所以重装前先关掉代理软件，或者关掉 TUN / 全局模式，再 SSH 连服务器。

### 节点突然连不上

SSH 连上服务器，运行内置的自测命令：

```bash
node-selftest
```

它会重新检测 Reality 和 Hysteria2 是否正常监听。如果 ISP 那边出了问题，脚本的自测可能会失败；按“住宅代理连不上”的步骤检查，或者找 ISP 商家。

## 方案二：配置住宅IP服务器

对应页面：https://re0claude.us.ci/plan2-residential-server/

### 换了一台机器，节点链接会变吗

会。节点链接和服务器绑定，换机器要重新运行脚本，重新导入客户端。

### 以后想换 IP 或换套餐

如果商家支持换 IP，先在后台换，再用新 IP 测一次；如果换了一台全新的服务器，就按本章从头做一遍。

### 测出来是 `hosting`，但商家说这就是住宅

以检测结果为准。先找商家换一台，换完再测；如果连续几台都是 `hosting`，可以考虑退款，换一家，或者回到选择方案看看方案一。

### 连续抽到机房 IP，还要不要继续抽

先确认自己没有测错：查的是服务器 IP 本身，不是商家后台里的域名，确实是 `hosting`，就让商家换机；一连两三台都是机房段，说明这个套餐大概率就是这个池子，退款换一家，或者回选择方案看方案一。别为了抽一台好机器反复付钱，抽卡的成本也是成本。

### 一台服务器能给两台电脑用吗

可以。节点就是这台服务器，两台电脑各自导入同一条节点链接就行，出口 IP 是同一个，Claude 看到的也都是这个住宅 IP。要注意的是账号：一个 IP 最好只挂一个主力账号，同一时间在线的设备控制在一两台（见日常维护那章的“控制登录设备”）。

### 装过了，想重装

在服务器上运行同一行脚本命令。脚本发现装过会先问你，输入 `y` 删掉旧的重新装，输入别的什么都不动。重装后节点链接会变，代理软件里要删掉旧节点，重新导入。

> [!caution] 重装前先关掉电脑上的代理软件
> SSH 可能正走在这台服务器的节点上。脚本一删旧节点，SSH 就断了，出现 `Connection to ... closed by remote host`。先关掉代理软件，或者关掉 TUN / 全局模式，再 SSH 连服务器。

如果已经遇到了，关掉代理（或者重启电脑）再连一次，重新运行命令就好。

### SSH 端口不是 22

有的商家后台会多写一个**端口**，是一串四五位的数字。这时候照正文输 `ssh root@你的服务器IP`，连 `password:` 都不会出现，屏幕上提示的是：

```text
ssh: connect to host 你的服务器IP port 22: Connection refused
```

原因很简单：一台服务器上跑着好几个程序，SSH 是一个，节点是另一个。请求送到服务器后，要靠**端口**决定交给哪个程序。SSH 默认住在 22 号门；商家如果把它改到了别的门，敲 22 号自然没人应。

在命令里加上小写 `-p`：

```bash
ssh -p 你的端口 root@你的服务器IP
```

`你的端口` 换成后台“端口”一栏的数字。后面和正文一样：问 `Are you sure...` 时输入 `yes`，出现 `password:` 时输入 root 密码。

### SSH 提示 Permission denied

输完密码回车，出现 `Permission denied, please try again.`，意思是服务器不认这个密码。

先仔细再输一两次。输密码时屏幕上什么都不显示，多一个空格、少一个字符都看不出来。还是不行，按顺序试：

1. **重置密码。** 在商家后台把 root 密码改成一个新的，关掉当前命令行窗口，新开一个重新连接。
2. **重启电脑**，再连一次。
3. **不用 SSH，从商家后台进服务器。** 后台一般有“登录控制器”“控制台”或“VNC”，点进去就是服务器的命令行。在里面用 root 和密码登录，直接把脚本命令粘贴进去运行。
4. **申请退款。** 上面都不行，就找商家退款；还想用这个方案，可以再买一台。

### 面板的用户名、密码、端口大家都一样，安全吗

用这个脚本装出来的面板，默认用户名 `admin`、密码 `123456`、端口 `8080`，每个人都一样。这是我故意设成一样的，最开始是为了方便远程帮大家排查问题。

别人知道了这套用户名密码，能不能登上你的面板？不能。面板只开在服务器本机，从外网直接访问打不开。要进面板，得先在自己电脑上运行：

```bash
ssh -L 8080:127.0.0.1:8080 root@你的服务器IP
```

这条隧道要输入你的服务器密码。也就是说，面板外面还有一道门，钥匙是服务器密码。**除非别人知道你的服务器密码，否则上不了你的面板。**

不改也行。想改的话，直接在面板里改最方便。改之前先弄清楚会影响什么：

- **面板的用户名、密码**：不影响节点，节点照常用。
- **面板的端口**：节点照常能用，但下次打开面板时，`ssh -L` 命令和浏览器地址里的 `8080` 要换成新端口；脚本的“每周自动更新 Xray 内核”还按旧端口找面板，会一直更新失败。没有特别理由，别改面板端口。
- **节点的端口**：节点会连不上。节点链接里写着端口，代理软件还在按旧端口连。改了要重新导出链接，在代理软件里删掉旧节点再导入。

面板里的位置（以 3x-ui v3.9.0 的简体中文界面为准，升级后菜单可能变）：

- 用户名、密码：**面板设置** → **安全设定** → **管理员凭据**。
- 面板端口：**面板设置** → **常规** → **面板监听端口**，保存后点“重启面板”。

## 客户端配置与环境验证：电脑端

对应页面：https://re0claude.us.ci/client-desktop/

### 系统代理那里选“清除系统代理”，是不是等于没开代理

不是。选“清除系统代理”只是不让软件去改系统的代理设置，流量由 Tun 模式接管；两个都开反而容易互相打架。确认界面上 Tun 是勾选状态、节点是选中的那个就够了。

### Tun 模式要一直开着吗

用代理软件期间就开着。Tun 是让整台电脑的流量都从节点过的那道闸；关掉它就等于关掉代理。国内网站走不走代理由分流规则决定，和 Tun 开不开是两件事。

### 走全局模式是不是更稳

更稳，但更慢：全局会把访问国内网站的流量也送进节点绕一圈。分流规则配好了就用分流，没必要全局常开；临时验证“节点到底通不通”时，可以切到全局试一下，再切回来。

### 规则集里要不要再加一条 block（阻断）规则

不要。阻断规则会把匹配到的流量直接堵死，Claude 反而打不开。只加一条让 Claude 走代理的规则，放在“绕过中国”的直连规则前面就够了。

### 主节点延迟 -1，或者一直超时，怎么办

先用备用节点。主节点是 VLESS，走 TCP；有的网络或商家会挡这个端口，备用节点走 UDP，晚高峰常常还更快。想排查主节点：在服务器上运行 `node-selftest` 看两个节点的自测是否成功；再回商家后台确认 **TCP 443** 和 **UDP 443** 已经放行。都正常还是 -1，多半是线路在挡，换备用节点用着就行。

### 主节点和备用节点可以同时开吗？两台电脑能一起用吗

可以。它们不是两个出口，而是同一台服务器上的两种协议，切换过去 Claude 看到的 IP 是一样的。两台电脑也可以同时用同一条节点链接。真正要控制的是账号：同一时间在线的设备别太多，也不要分给朋友（见日常维护那章的“控制登录设备”）。

### 只有某一个网站打不开，是节点坏了吗

先看别的网站。别的都正常，说明节点和配置没问题，问题在那个网站或那条规则上（有的网站要注册才可以观看，如 youtube）；别的也都打不开，再按顺序查：重开一次 Tun、重启代理软件、看服务器自测。

### 怎么确认现在真的走的是住宅出口

看三个地方：打开 [ipinfo.io](https://ipinfo.io/)，第一行 IP 应该是节点的出口——方案一是 ISP 的 IP，不是服务器 IP；AS Type 是 `isp`、Privacy 是 `false`；再用 browserleaks 和 ipleak 确认没有国内的 DNS 和 IPv6。

### 改成台湾时区、IP 在美国，这样对得上吗

允许。Claude 更在意“地区是否受支持、时区名字是否自洽”，不要求和 IP 在同一个城市。想更稳妥，就选住宅 IP 所在城市的时区；只要不是中国大陆和香港，名字能对上就行，别用 `Asia/Shanghai`。

### 换 WiFi、出门用手机热点，会不会露出真实 IP

只要代理还在、Tun 正常，出口就还是节点，换网络本身不影响 Claude 看到的 IP。真正会露的是代理断了还继续访问 Claude——分流规则正常时，节点断了只会超时打不开，不会自动切回本地直连。

### 测出来好几个不同的 IP

`ipinfo.io` 上是一个 IP，商家后台写的是另一个，别的测 IP 网站又是一个，DNS 检测里还有别的。这些 IP 各是各的东西，不一定是哪里出错。

先回忆方案一的结构：请求先到服务器，**只有 Claude 和 `ipinfo.io` 再从服务器转给 ISP**，其他网站从服务器自己的出口出去。按这个去对：

- **`ipinfo.io` 上看到的是 ISP 的 IP。** 它是住宅 IP，也是 Claude 看到的那个。
- **商家后台、别的测 IP 网站看到的是服务器 IP。** 服务器大多是机房 IP；ISP 流量少，所以只让 Claude 和 `ipinfo.io` 走它。
- **DNS 检测里列出来的是 DNS 服务器的 IP。** 防泄漏那一步让代理软件通过 Cloudflare、Google 这些服务去查，所以显示的是它们的地址，不是你的，也不在国内，这正是我们想要的。
- **WebRTC 检测里 Local IP、Public IP 显示 `-`**，说明 WebRTC 已经被管住，什么 IP 都没交出去，也是对的。

方案二没有 ISP 这一层，`ipinfo.io` 和其他网站看到的都应该是服务器的住宅 IP。如果不一样，先检查代理是不是全局生效。

### 分流规则具体怎么写

方案一、二的脚本只在服务器上做分流，管的是“到了服务器之后哪些走 ISP”。客户端到节点这一段仍要自己保证 Claude 走代理。这里说的是你已经有别的基础节点、只想让 Claude 走住宅节点的情况。

至少要包含这几个域名：`claude.ai`、`claude.com`、`anthropic.com`，再加上用来检测的 `ipinfo.io`。

**Clash Verge（mihomo 内核）**：在规则里加上下面几行，`住宅节点` 换成你的节点或策略组名字，并放在其他规则前面：

```text
- DOMAIN-SUFFIX,claude.ai,住宅节点
- DOMAIN-SUFFIX,claude.com,住宅节点
- DOMAIN-SUFFIX,anthropic.com,住宅节点
- DOMAIN-SUFFIX,ipinfo.io,住宅节点
```

**Shadowrocket**：在“配置”→“规则”里新增 `DOMAIN-SUFFIX` 类型的规则，域名同上，策略选住宅节点。

**v2rayN**：照上面“配置v2rayN 规则集”的做法，把 `claude` 规则设成 `geosite:anthropic` → `proxy`，再把当前服务器切到住宅节点。v2rayN 的规则只能选“代理 / 直连 / 阻断”，不能直接指定某一个节点，所以“走哪个节点”靠当前选中的服务器决定。

看不懂也没关系：不分流，用 Claude 时全局走住宅节点，最不容易出错。

## 客户端配置与环境验证：iOS 端

对应页面：https://re0claude.us.ci/iphone-prepare/

### 小火箭导入节点后连不上

小火箭（Shadowrocket）也能用，但有的版本和脚本装出来的主节点（VLESS）配合不好，导入后怎么都连不上。遇到这种情况，不用排查，直接换一个代理软件：

- **V2Box**：免费，有一点广告。这一章用的就是它。
- **Tunna**：免费，没有广告，但很多群友反馈搜索不到。

下载方式见上面“准备一个能下载代理软件的 App Store”：临时换到奥地利，付款方式选 **EPS**，Bank 选 **Bank Austria**，PLZ 填 `1010`，下载完可以把地区改回中国大陆。换区会取消这个账户上正在自动续期的订阅，先想清楚再换。

## 账号注册与订阅全流程：iOS 端

对应页面：https://re0claude.us.ci/iphone-subscription/

### 创建美区 Apple ID 时提示“此时无法创建你的账户”

多半和当前网络环境、以及同一台设备短时间内建过账号有关。换一台设备（手机换电脑）、换一个干净的住宅出口再试，隔一两天再来。

### 账单地址填免税州的地址，算不算资料造假

不算。地址要真实存在、格式正确，选哪个州只影响要不要额外交销售税。付款走的是 App Store，Claude 那边看不到你的账单地址。

### 礼品卡能不能换个渠道买，比如亚马逊

不推荐亚马逊：它不支持支付宝，对礼品卡的购买风控也很严。教程用的是 Pockyt Shop，能用支付宝付。换别的正规渠道也可以，但别买来路不明的便宜卡，便宜得离谱的很可能是黑卡，兑换之后 Apple ID 可能被锁。

### 兑换礼品卡时提示“地区不支持”

先确认两件事：兑换时 App Store 里登录的是**美区**账号；兑换时开着住宅节点，出口不是机房。两件都对还失败，就是这张卡本身的问题，找卖家换一张——这类问题没有通用解法，别反复试，失败的次数多了账号更危险。

### 没有苹果设备，能借一台 iPhone 订阅吗

可以。订阅是挂在 Claude 账号上的，和 Apple ID 无关：在借来的 iPhone 上登录你的美区 Apple ID，在 Claude App 里付完款，退出登录就行，之后你在自己电脑上照样用。注意只在 **App Store** 里登录美区账号，不要在“设置”顶部登录。不想借设备，就走安卓端的 Google Play。

### iOS 这条路一定要有外币卡吗

不需要。这条路线全程用礼品卡余额付款，不填任何卡。要用卡的是安卓的 Google Play 那一路，以及你自己想用网页端订阅的情况。

### 退款能退到卡里吗，封号了能退吗

退款一般只退回 App Store 的余额，提不出来。封号之后能不能退，要看 Apple 客服的判断，不是必然；退款也是走 Apple 支持，流程和“购买未完成”一样靠客服沟通。别打算退完款换个号接着用同一套环境。

### 一个美区 Apple ID 能付几个 Claude 账号的订阅

技术上可以，但没必要。一个 IP 上冒出几个新号，看起来就是在批量注册；教程里也写了，一个 IP 只注册和使用一个主力账号。真要帮家人订，至少给另一个账号准备独立的出口。

### 遇到 KYC 身份验证

KYC 是身份验证，要求你证明“你是你”。很抱歉，我没有遇到过 KYC，也没有找到可靠的解决方法，所以没法给出验证过的步骤。遇到的话，可以去官方支持中心看看，或者到社区里找有实际经验的人。

## 账号注册与订阅全流程：安卓端

对应页面：https://re0claude.us.ci/android-subscription/

### 没有 Google 服务的国行手机，能订阅吗

先按上一章把 Google Play 装上；实在装不上，可以借一台带 Google 服务的手机或模拟器完成订阅，订阅跟着 Claude 账号走，之后回到自己手机上登录照样用。也可以看 iOS 那章，借一台 iPhone 走礼品卡。

### Google Play 绑什么卡，国内卡有风险吗

教程里的群友用的是国内发行的万事达卡，绑上就能用。国内发行的卡有被风控的可能，我的建议是：能用，但订阅成功之后不要反复改付款方式，也不要连续重试失败的订单。

### 支付宝能不能直接给 Google Play 充值

不能。Google Play 的余额要用 Google Play 礼品卡充，而礼品卡兑换对地区和网络的要求很死：卡区、账号国家必须一致，兑换时的出口也不能像机房。所以安卓这条路，多数人还是直接用卡付。

### 安卓能不能用礼品卡余额付款

不确定是否可以，有群友给 Google Play 礼品卡充值了，但是无法使用。推荐走绑卡路线。

### 换了手机或者重装 App，订阅会丢吗

不会。订阅跟着 Google 账号和 Claude 账号走，换手机重新登录 Google Play 和 Claude，在“订阅”里就能看到；扣款也照旧。换了设备记得代理和时区重新设一遍，别在新手机上裸连着登录。

## 日常维护、风控与常见问题

对应页面：https://re0claude.us.ci/maintenance/

### 这样搞到底会不会被封

我没法保证。能做的都做到之后，风险会小很多，但不是零：干净的住宅出口、不频繁换 IP、不同时挂太多设备、不猛刷额度、不拿账号做反代。任何说“包不封”的方法都别信。

### 被封了怎么申诉，要等多久

到 Anthropic 官方支持中心提交复核申请，写清你是个人用户、账号只有自己在用、没有共享也没有接脚本（上面有模板）。回复时间没有准数，快的一两天，慢的一周多；不用一直重复提交，隔几天补一封说明就行。申诉期间保持同一个干净的出口，别急着换环境。

### 免费号、方案一还能不能白嫖

不太划算了。免费得来的住宅线路随时可能断，教程开头那次就是这么断的；住宅 IP 的价格也已经接近住宅服务器。想长期用，方案二一台机器跑一次脚本更省事。免费额度可以先用着，把整套流程走通，再决定要不要订阅。

### 新号要养几天，能不能注册完马上订阅

先像普通人一样用两三天，把免费额度用完，等它主动弹出升级提示再订阅。秒充很容易撞风控，轻则弹 KYC，重则直接封。Google 账号也一样，先用两天（见iOS 端和安卓端的“先用两天”）。

### 换 IP、换服务器或换商家，旧账号受影响吗

能不动就别动。已经稳定用了两周以上的，到期直接续费，别手痒换机。非换不可：新 IP 先按第 2 章的标准测一遍，退出登录，隔一会儿再从新出口登录，别在新旧两个 IP 之间来回切。任务跑到一半断线也是一样，恢复之后保持同一个出口继续。

### 任务跑到一半断网或切了节点，会出事吗

分流规则正常时，节点断了只会超时打不开，不会自动切回本地直连；恢复代理、保持同一个出口继续就行，不会因为一次断线就出事。真正危险的是断网之后没开代理还去访问 Claude。

### 一个 IP 能登几个号，和朋友合租行不行

教程没写合租，也不建议：一个 IP 最好只有一个主力账号，同一时间一两台设备。多人共用一个出口，等于把别人的操作风险绑在你的账号上；真出问题，申诉时也很难说清。

### 额度怎么算，周额度什么时候刷新

有两层限制：5 小时内的额度和一周的总额度。周额度固定周一刷新，和你哪天订阅无关；用量在 Claude 的 usage 页面能看。别把周额度当成可以随便刷，也别指望重置卡之类的东西。

### Opus 额度掉得太快怎么办

可以把活分出去：让 Opus 出计划、写提示词，便宜的模型干活，最后再让 Opus 审一遍。Pro 全用 Opus 确实不太够；还不够再考虑 Max，但它贵得多，新号一上来就上大额度，也更容易被风控盯上。

### 能不能把网页版账号接第三方 API 或反代

不要。这是官方打击力度最高的行为之一，网页版 Pro 只供你在官方网页和 App 里自己用。

### 用中文界面、用中文聊会不会被风控

不会。Claude 支持中文，界面和回复都能用中文；会露馅的是 IP、DNS、时区、账号这些，不是语言。
