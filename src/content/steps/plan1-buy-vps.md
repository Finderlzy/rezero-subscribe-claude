---
title: 买服务器
---
在 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买一台云 VPS，按下表选。注意买的是**云 VPS**，不是它家的住宅服务器（住宅服务器我买过一次，测出来是机房 IP，见[[plan2-buy-residential-vps|方案二]]）。

| 选项   | 怎么选                                                |
| ---- | -------------------------------------------------- |
| 系统   | **Ubuntu 22.04 / 24.04** 或 **Debian 12** |
| 配置   | 1 核 CPU、1 GB 内存就够                                  |
| 流量   | 每月几百 GB 足够                                         |
| 机房位置 | 美国、日本、新加坡等                                         |

买完在商家控制台记下**服务器 IP** 和 **root 密码**。

> [!why] VPS 和住宅 IP 各管什么
> 这是我自己在用的方案，也是视频里录的方案。VPS 负责“翻出去”，住宅 IP 负责“最后一跳”。
