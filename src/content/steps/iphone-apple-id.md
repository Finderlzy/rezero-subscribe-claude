---
title: 注册美区 Apple ID
skippable: true
skipLabel: 已有美区 Apple ID，跳过
---
1. 浏览器（手机、电脑都行）打开 appleid.apple.com → 点右上角箭头 →“创建你的 Apple 账户”。

![[订阅claude-AppleID-1-打开网址.jpg|262]]
![[订阅claude-AppleID-2-创建账户.jpg|262]]

2. 国家/地区选“**美国**”；姓名可以填拼音；生日要满 18 岁；邮箱用没注册过 Apple ID 的 Gmail；手机号可以用 +86。

![[订阅claude-AppleID-3-选择美国.jpg|262]]

3. 完成邮箱和手机验证。
4. 重新登录一次，确认地区是美国。付款方式不用填。

> [!why] 用美区 Apple ID 的余额订阅
> 我用的是 iPhone，所以只写了苹果的方法：**美区 Apple ID + 礼品卡充值余额 + 在 claude 的 iOS app 里直接订阅**。
>
> 用国内的卡直接订阅，基本不用想。用这个方法，anthropic 看到的付款方是美区 App Store。支付宝只用来买礼品卡，不会直接出现在 claude 的订阅里。
