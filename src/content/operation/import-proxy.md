# 导入代理软件

先记住三条：

- **打开 tun 模式，不要用“自动配置系统代理”之类的选项。**
- 方案一、二有两个节点：**平时用主节点**（VLESS + Reality），主节点连不上或很慢时换备用节点（Hysteria2）。两个节点出口是同一台服务器，切换不算“换节点”。
- **用 claude 时固定用这一个节点，不要换来换去。**

**电脑：v2rayN**

1. 从 GitHub 下载 [v2rayN](https://github.com/2dust/v2rayN/releases)，选和你的系统对应的版本，解压。
2. 右键 v2rayN → **以管理员身份运行**。
3. 复制节点链接，在 v2rayN 里：配置项 → 从剪贴板导入。
   - 方案一、二：节点是运行脚本最后打印的那两个，**通过剪贴板导入**，不要截图发来发去。
   - 方案三：复制商家给的订阅链接，同样从剪贴板导入。
4. 选中主节点，设为当前使用的节点。
5. 主界面底部：系统代理选“清除系统代理”，打开“启用 Tun”。
6. 确认 claude 走代理：不管用“规则”还是“全局”模式，claude 相关的域名都不能直连。不放心的话，用 claude 时直接开全局。

**电脑：Clash Verge**

1. 从 GitHub 下载 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)，安装。
2. 导入节点：
   - 方案一、二：Clash Verge 导入不了 `vless://`、`hysteria2://` 这种分享链接。在服务器上运行 `cat /root/clash.yaml`，复制全部内容，在 Clash Verge 里新建一个本地配置粘贴进去保存。两个节点都在里面，默认选中备用节点 Hysteria2（Clash 的内核连 Reality 节点目前有兼容问题，还在排查）。
   - 方案三：复制商家给的订阅链接，在 Clash Verge 里导入订阅。
3. 设置 → 系统设置：打开“虚拟网卡模式”（也就是 tun 模式），第一次打开会提示安装服务模式，照着装上；“系统代理”保持关闭。
4. 和 v2rayN 一样，确认 claude 相关的域名不会直连。

**手机**

手机现在先不用管，等到注册 Gmail 之前再导入，见 [[选择手机系统]]。
