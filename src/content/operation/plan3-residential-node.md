# 方案三：直接买住宅节点

**一定要选 1 人独享，不要买共享套餐。**

1. 在 ipequal 注册，购买套餐，**“使用类型”选 1 人独享**（IP 质量怎么样，见 [[实测：ipequal 住宅节点|它的实测]]）。我**没用过**，因为一直买不到，是看到很多大佬推荐才放在这里，建议先买一个月试试。
   - 还没有节点：[ipequal](https://www.ipequal.com/?ref=6adabd0307)（国内可直接打开）
   - 已经有节点：[ipequal](https://www.equaldcdn.com/?ref=6adabd0307)（需要开代理打开）
2. 复制订阅链接，按 [[导入代理软件]] 导入，**尽量通过剪贴板导入**。
3. 已经有别的节点的，也可以只让 claude 走住宅节点，见 [[分流规则具体怎么写？]]。用了分流的，测 IP 之前要把 `ipinfo.io` 也加进分流规则，否则测出来的是原来节点的 IP。

“1 人独享”怎么确认真的只有你在用，见 [[“1 人独享”怎么确认真的只有我在用？|常见问题]]。
