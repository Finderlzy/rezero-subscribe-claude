# 二、购买服务器

1. 在 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买一台云 VPS（我用的就是它家的云 VPS。它是机房 IP，不用测它的 IP 质量），按下表选：

| 选项   | 怎么选                                |
| ---- | ---------------------------------- |
| 系统   | **Debian 12**（不要选 Ubuntu）             |
| 配置   | 1 核 CPU、1 GB 内存就够                  |
| 流量   | 每月几百 GB 足够                         |
| 机房位置 | 美国、日本、新加坡等                         |

已经装成别的系统的，在商家后台把系统重装成 Debian 12。

2. 买完在商家控制台记下**服务器 IP** 和 **root 密码**。
