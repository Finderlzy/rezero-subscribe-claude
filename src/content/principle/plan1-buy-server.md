# 一、购买服务器

在动手之前，先讲一点网络的基础知识。

你有没有想过：为什么在浏览器里打开 claude.ai，就能看到一个网页？其实这背后是一来一回两件事。你按下回车的时候，你的设备向 claude 的服务器发出了一个**请求**，意思是“我要看这个网页”；claude 的服务器收到请求后，把网页的数据通过网络**返回**给你，你才看到了网页。

问题就出在“返回”这一步。服务器要把数据送回来，就得知道该送到哪儿，所以每个请求上都带着一个“回信地址”，这个地址就是 **IP**。你可以先简单理解成：每一台上网的设备都有一个 IP（这么说不是十分准确，但够用了）。

IP 不只是一个地址，它还能看出你在哪个国家。claude 不对中国用户提供服务，它的服务器一看请求来自中国的 IP，就会制裁你。也就是说，**claude 判断你是不是中国用户，最主要看的就是 IP。**

既然 claude 看的是 IP，那我们要做的就是：**让发给 claude 的请求，带着一个海外的 IP**。我们自己的 IP 改不了，那就找一台海外的服务器帮忙。我们先把请求交给这台服务器，由它替我们发给 claude。claude 看到的是这台服务器的海外 IP，就不会制裁了。claude 把数据返回给服务器，服务器再转交给我们。

这台替我们收发请求的海外服务器，就是常说的“**节点**”。这就是这一节要买服务器的原因。

1. 在 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买一台云 VPS（我之前用的就是它家的云 VPS。云 VPS 是机房 IP，访问 claude 时走的是 ISP，所以不用看它的 IP 质量），按下表选：

| 选项   | 怎么选                                |
| ---- | ---------------------------------- |
| 系统   | **Debian 12**（不要选 Ubuntu）             |
| 配置   | 1 核 CPU、1 GB 内存就够                  |
| 流量   | 每月几百 GB 足够                         |
| 机房位置 | 美国、日本、新加坡等                         |

系统只选 Debian。我自己用的就是 Debian，教程里的命令和脚本都是照着 Debian 来的。Ubuntu 和 Debian 是一家子，长得很像，但有读者反馈，Ubuntu 上有些命令有些许区别，照着教程做容易出岔子，所以干脆统一用 Debian。已经装成别的系统的，在商家后台把系统重装成 Debian 12 就行。

有的商家最高只提供 Debian 11。Debian 11 官方已经停止支持，以后不会再有安全更新，原来的软件源也用不了了。选 Debian 11 也行：脚本会先自动把系统原地升级到 Debian 12 再装节点，多花 5～15 分钟。

2. 买完在商家控制台记下**服务器 IP** 和 **root 密码**。
