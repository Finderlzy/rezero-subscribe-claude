# 整体思路

我的理解是：anthropic 会从很多地方判断你是谁、在哪里，比如 IP、DNS、浏览器、时区、账号地区、付款方式。**只要其中一项露出“我其实在国内”，就有风险。**

所以下面每一步，其实都在做同一件事：**让每一项信息都不露出“我在国内”，而且像一个普通用户。**

**整体流程：** 清理旧账号和配置 → 选择方案，准备节点和住宅 IP → 导入代理软件 → 测 IP 质量 → 防泄漏 → 改时区 → 手机导入代理软件、下载 Gmail（iPhone 和安卓分开走）→ 注册 Gmail → 登录谷歌浏览器 → 先用两天 → 修改 Google 账号地区 → 注册 claude → 订阅（iPhone 和安卓分开走）→ 订阅之后。
