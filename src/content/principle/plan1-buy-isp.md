# 四、购买 ISP 代理

上一节让我们的请求带上了海外的 IP，请求能到达 claude 了。但只做到这一步还不够：claude 不光看你从哪个国家来，还会看你像不像一个普通人。不像的话，照样会被封号。

它怎么判断你像不像普通人呢？还是看 IP。IP 除了能看出国家，还能看出类型。每个 IP 都登记在某个组织名下，网站一查就知道：

- **机房 IP**：我们买的服务器放在机房里，它的 IP 登记在云服务商名下。普通人不会从机房上网，所以 claude 的风控一看到机房 IP，就容易把你当成在用代理，封号的风险就高了。
- **住宅 IP**：登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在家上网。
- **ISP**：也叫静态住宅 IP，是运营商的 IP 放在机房里长期固定使用，也算住宅这一类，被封号的概率比较低。

我们的服务器是机房 IP，所以要在节点外面再套一层 ISP 代理。套上之后，请求还是先到服务器，但访问 claude 的时候，服务器不从自己的出口出去，而是把请求转交给 ISP 代理，由它发给 claude。这样 claude 看到的就是 ISP 的 IP。

简单来说，这两层各管一件事：**服务器让请求能到达 claude，ISP 代理让 claude 觉得你是普通人，不封你的号。**

那是不是所有网站都要走 ISP 呢？这个由你自己决定，脚本会问你选哪一个：

- **只有 claude 走 ISP**：只有 anthropic 相关的网站（还有用来检查 IP 的 ipinfo.io）走 ISP，其他网站照旧从服务器出去。这是我自己用的。ISP 的流量只花在刀刃上，看视频、刷网页都不占它的流量，网速也不受 ISP 影响。
- **全部走 ISP**：不管访问什么网站，看到的都是 ISP 的 IP。代价是 ISP 的流量用得快，白嫖的那点额度可能撑不了多久，网速也要看 ISP 的脸色。

拿不准的话，选第一个。选错了也没关系，再运行一次同一行命令，重新选就行。

第一步白嫖到的 ISP，现在要把它配到节点上。

如果白嫖到的 ISP 质量不好，推荐买 [Decodo](https://decodo.com/)（见 [[实测：Decodo ISP|它的实测]]），它在 Proxyway 2026 年的 ISP 代理测试里排第一，就是贵一些。
