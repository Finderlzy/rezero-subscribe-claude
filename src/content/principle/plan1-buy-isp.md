# 二、购买 ISP 代理

上一节买的服务器在海外，等它变成节点，我们的请求就能带上海外的 IP，到达 claude 了。但只做到这一步还不够：claude 不光看你从哪个国家来，还会看你像不像一个普通人。不像的话，照样会被封号。

它怎么判断你像不像普通人呢？还是看 IP。IP 除了能看出国家，还能看出类型。每个 IP 都登记在某个组织名下，网站一查就知道：

- **机房 IP**：我们买的服务器放在机房里，它的 IP 登记在云服务商名下。普通人不会从机房上网，所以 claude 的风控一看到机房 IP，就容易把你当成在用代理，封号的风险就高了。
- **住宅 IP**：登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在家上网。
- **ISP**：也叫静态住宅 IP，是运营商的 IP 放在机房里长期固定使用，也算住宅这一类，被封号的概率比较低。

我们的服务器是机房 IP，所以要在节点外面再套一层 ISP 代理。这一层不用自己动手，下一步运行脚本时把 ISP 填进去，脚本会帮你套好。套上之后，请求还是先到服务器，但访问 claude 的时候，服务器不从自己的出口出去，而是把请求转交给 ISP 代理，由它发给 claude。这样 claude 看到的就是 ISP 的 IP。

简单来说，这两层各管一件事：**服务器让请求能到达 claude，ISP 代理让 claude 觉得你是普通人，不封你的号。**

那是不是所有网站都要走 ISP 呢？不用。脚本只让 anthropic 相关的网站（还有用来检查 IP 的 ipinfo.io）走 ISP，其他网站照旧从服务器出去。我用方案一时就是这么设置的。ISP 的流量只花在刀刃上，看视频、刷网页都不占它的流量，网速也不受 ISP 影响。

推荐买 [Decodo](https://decodo.com/)。先说明：**我自己没有用过 Decodo**，推荐它只是因为它在 Proxyway 2026 年的 ISP 代理测试里排第一；它的价格很贵。不管在哪家买，都要选 **SOCKS5** 协议，脚本只支持 SOCKS5。

买完在商家后台记下**住宅 IP、端口、用户名、密码**，下一步运行脚本时要填。这里的住宅 IP 可能是一串域名，比如 `r52u2gaa.isp201.iisp.asia`，这很正常，照着记下来就行。

**先测一下质量**

不管从哪里买的，拿到之后都先测一下质量，再决定要不要用。每个人拿到的 IP 都不一样，别人测出来好，不代表你拿到的也好。

商家给的是代理的地址，不是它的出口 IP，所以要先通过这个代理访问一次 ipinfo.io，拿到出口 IP：

1. 先关掉电脑上的代理软件，否则测出来的 IP 不对。
2. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
3. 输入下面这行，`用户名`、`密码`、`地址`、`端口` 换成上面记下的：

```bash
curl -x socks5h://用户名:密码@地址:端口 https://ipinfo.io/json
```

4. 返回结果里 `"ip"` 那一行就是出口 IP，把它复制下来。
5. 打开 `https://ipinfo.io/` 加上这个 IP（比如 `https://ipinfo.io/1.2.3.4`），看 AS Type 和 Privacy；再把这个 IP 粘贴到 [scamalytics.com](https://scamalytics.com/) 查风险分。怎么看，见 [[测 IP 质量]]。

连不上的话：

- 密码里有 `@`、`:`、`#` 这类符号，命令会被拆错。可以在商家后台换一个只有字母和数字的密码。
- 商家后台有 IP 白名单的话，把你自己现在的 IP 加进去。

**测出来质量不好**

可以找商家客服换一个 IP，换完再测一次；也可以回到 [[选择方案]]，换别的方案。
