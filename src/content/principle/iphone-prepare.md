# 客户端配置与环境验证：iOS 端
---

iPhone 和 iPad 上的代理比电脑简单一些。iOS 的代理软件以 **VPN** 的方式工作，打开之后整台手机的流量都要先经过它，所有 App 都逃不掉，相当于系统自带 Tun 模式。这一章要完成三件事：下载代理软件、导入节点、把手机环境调到和节点一致。

```text
准备外区 App Store
   ↓
下载 V2Box
   ↓
导入节点并连接
   ↓
改时区，做连通性测试
   ↓
下载 Gmail
```

## 准备一个能下载代理软件的 App Store
---

国区 App Store 搜不到代理软件，要下载就得先换到别的国家或地区。如果你已经有美区或其他外区的 Apple ID，直接登录下载即可，可以跳过这一节；如果只有国区账号，可以临时把 App Store 换到奥地利。奥地利支持 **EPS** 付款方式，选银行、填地址就行，不用填卡号。

> [!caution] 换区会取消自动续期订阅
> 换地区时，这个账户里所有自动续期的订阅都会被取消，App Store 会提示你。如果你有正在续期的订阅，先想清楚。下载完代理软件后，可以按同样的步骤把地区改回中国大陆。

打开 App Store，点右上角头像，再点最上面的账户名，验证面容 ID 或密码；进入“国家/地区”，搜索并选择“奥地利”。提示订阅会被取消时点“继续”，条款是德语的，直接点“同意”。

付款方式选 **EPS**，Bank 选 **Bank Austria**，不用填卡号。账单地址的 PLZ 填 `1010`，其他写着 Erforderlich 的必填项随便填，最后点右上角的 ✓ 保存。

**视频 05-1：把 App Store 换到奥地利**

换好之后，在 App Store 搜索 **V2Box**，下载安装。V2Box 免费，带一点广告。下完可以把地区改回中国大陆，已经下载的 App 不受影响；以后更新 V2Box 时，可能需要再切回外区。

### 小火箭用不了怎么办

小火箭（Shadowrocket）也能用，但有的群友导入节点后怎么都连不上。脚本装出来的主节点是 VLESS 协议，可能某些版本的小火箭和它配合得不好。遇到这种情况，直接换 V2Box，不用排查。

## 在 V2Box 里导入节点
---

复制节点链接：方案一、二复制脚本最后打印的主节点（`vless://` 开头）；如果你还有别的住宅节点，复制商家给的订阅链接。

打开 V2Box，第一次启动会引导你做快速设置：界面样式随便选，路由预设选 **China**，点 **Get Started**。进入“配置”，点右上角的“＋”，选“从剪贴板导入”，选中节点；回到主页滑动“滑动连接”，允许 VPN 配置。

**视频 05-2：用 V2Box 导入节点并连接**

> [!note] 为什么选 China
> 选 China 表示国内网站和应用直连，只有访问海外服务时才走节点。这样平时刷微信、看国内视频不绕路，也节省节点的流量。

连接成功后，手机的所有流量都会经过 V2Box。和电脑一样，固定用这一个节点，不要今天这里明天那里。

## 调整手机环境
---

### 改时区

iOS 的时区有两个开关，都要关。先打开设置 → 隐私与安全性 → 定位服务 → 系统服务（滑到最底下）→ 关闭“设定时区”；再打开设置 → 通用 → 日期与时间 → 关闭“自动设置” → 手动选择城市。

**视频 05-3：改 iOS 时区**

只关“自动设置”、不关定位服务里的“设定时区”的话，手机可能还会根据定位把时区改回来。时区选 Claude 支持的地区，比如台湾、新加坡；不确定就选住宅 IP 所在城市的时区。中国大陆和香港不行。

### 语言与地区（可选）

设置 → 通用 → 语言与地区。这一项不是必须的，但如果你希望手机看起来更像一个海外用户，可以把“地区”改成和时区一致的地方。

### iCloud 专用代理

如果你开通了 iCloud+，并且打开了“专用代理（Private Relay）”，建议在使用 Claude 期间关掉它：设置 → 最上方 Apple ID → iCloud → 专用代理 → 关闭。

专用代理可能接管 Safari 的流量，让请求从另一个出口出去，导致你的 IP 频繁变化。不是每个账号都有这个功能，没有就不用管。

### 验收

保持 V2Box 连接，用 Safari 打开 [ipinfo.io](https://ipinfo.io/)，确认页面顶部显示的 IP 是你的节点出口，AS Type 是 `isp`，Privacy 是 `false`。再打开 [ipleak.net](https://ipleak.net/)，确认没有出现国内的 DNS 或 IPv6 地址。

如果几个网站显示的 IP 不一样，先看[[日常维护、风控应对与常见故障#测出来好几个不同的 IP|日常维护与故障处理]]里的“测出来好几个不同的 IP”。

## 下载 Gmail
---

确认 V2Box 已经连接，在 App Store 里搜索 **Gmail**，认准开发者是 Google，下载。很多 iPhone 自带 Gmail，已经有的就不用再下。
