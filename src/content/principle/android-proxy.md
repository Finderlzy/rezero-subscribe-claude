# 安卓：导入代理软件

手机上的代理软件和电脑上的不太一样，它是以 **VPN** 的方式工作的：打开之后，整台手机的流量都要先经过它，所有 app 上网都逃不掉，相当于自带 tun 模式，不用另外设置。

安卓上我推荐用 v2rayNG。它放在 GitHub 上，可手机还没走代理，GitHub 很可能打不开。所以可以借一下电脑：电脑上的代理已经弄好了，在电脑上下载，再传到手机上。

**操作**

1. 下载 [v2rayNG](https://github.com/2dust/v2rayNG/releases)。手机上打不开 GitHub 的话，就在已经开了代理的电脑上下载安装包（选 `.apk` 结尾的），再传到手机上安装。
2. 复制节点链接，在 v2rayNG 里：右上角“＋”→ 从剪贴板导入。
3. 点右下角的按钮启动，第一次会问要不要允许建立 VPN 连接，选允许。

导入之后，确认 claude 走的是你的节点。和电脑一样，手机上也**固定用这一个节点**，不要换来换去。
