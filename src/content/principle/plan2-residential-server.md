# 方案二：住宅 IP 服务器

先讲一点网络的基础知识。你在浏览器里打开 claude.ai 的时候，你的设备向 claude 的服务器发出了一个**请求**；claude 的服务器收到后，把网页的数据**返回**给你，你才看到了网页。服务器要把数据送回来，就得知道该送到哪儿，所以每个请求上都带着一个“回信地址”，这个地址就是 **IP**。

IP 不只是一个地址，它还能看出两件事：

- **你在哪个国家**。claude 不对中国用户提供服务，一看请求来自中国的 IP，就会制裁你。
- **你是什么人**。每个 IP 都登记在某个组织名下：普通服务器放在机房里，IP 登记在云服务商名下，叫**机房 IP**，普通人不会从机房上网，claude 一看就容易把你当成在用代理；**住宅 IP** 登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在家上网。

所以我们要让 claude 看到的，是一个**海外的住宅 IP**。

方案二的做法，就是直接买一台**住宅服务器**。它是一台放在海外、自带住宅 IP 的服务器，从它这里出去的请求，claude 看到的直接就是住宅 IP。所以你**只需要把这台服务器变成一个节点**就好了：请求先交给它，由它替你发给 claude，claude 看到的就是这台服务器的住宅 IP；claude 返回的数据，再由它转交给你。这台替你收发请求的服务器，就是常说的“**节点**”。

不过要注意一点：**商家说是住宅服务器，分到你手上的不一定真是住宅 IP。** 我自己就买过一台 VoyraCloud 的美国住宅服务器（见 [[实测：VoyraCloud 住宅服务器|它的实测]]），测出来 ipinfo.io 显示 ASN 属于 Bunny Communications，类型是 **Hosting（机房）**，Privacy 为 true；Scamalytics 分数 16，属于低风险，但也识别出在用 VPN/代理。也就是说，我这一台风险分数不高，但分到的是机房 IP，不是住宅 IP。

这只是我一次购买的结果，不代表每次都这样。所以买到之后一定要测，后面“测 IP 质量”那一步会讲怎么测；不是住宅 IP 的话，找商家退款或者换 IP。

**2. 连上服务器**

服务器在海外，它没有屏幕，也没有键盘，我们人在中国，该怎么操作它呢？这个时候就轮到 **SSH** 登场了。SSH 是一项远程连接技术：连上之后，你在自己电脑上敲的命令，会被送到海外的服务器上执行，执行的结果再传回你的屏幕，就好像你坐在那台服务器面前一样。

要连上服务器，需要两样东西：服务器的 IP，告诉 SSH 要连到哪一台；root 密码，证明你是这台服务器的主人。就是刚才记下来的那两样。

1. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
2. 输入下面的命令，`你的服务器IP` 换成真实 IP。问 `Are you sure...` 时输入 `yes`；出现 `password:` 时输入 root 密码（**屏幕不显示，正常**），回车。开头变成 `root@...:~#` 就连上了。

```bash
ssh root@你的服务器IP
```

**3. 把服务器变成节点**

刚买来的服务器只是一台空电脑，什么都不会做。要让它替我们收发请求，就得在上面装一个专门干这件事的程序，这个程序叫 **Xray**。装好 Xray，这台服务器才真正变成了节点。

这些事手动做要敲很多命令，我把它们写成了一个脚本，你只要运行一行命令就行。脚本装好 Xray 之后，会让服务器自己连一次自己的节点，确认能用，再把节点链接打印出来。这条链接就是你连接这个节点要用的东西，等一会要把它导入代理软件。

4. 最后会打印两个节点，**通过剪贴板**或扫二维码导入代理软件，**不要发给别人**：

   - **备用节点**：`hysteria2://` 开头，主节点连不上或很慢时换它。忘了就运行 `cat /root/hy2.txt`。
5. 商家后台有防火墙/安全组的话，放行 **TCP 443 和 UDP 443**。

脚本内容公开在 [reality-setup](https://github.com/Finderlzy/reality-setup)，运行前可以先看一眼。

服务器本身就是住宅 IP，所以不用再套一层 ISP 代理，节点到这里就弄好了。
