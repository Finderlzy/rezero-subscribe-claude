# 方案三：直接买住宅节点

方案一、二都要自己买服务器、敲命令，把服务器变成节点。如果你完全不想碰服务器呢？

那就直接买一个**现成的住宅节点**。服务器、Xray、住宅 IP，商家都帮你准备好了，你买到的就是一个订阅链接，导入代理软件就能用。比如 ipequal（IP 质量怎么样，见 [[实测：ipequal 住宅节点|它的实测]]），它卖的是 VLESS Reality 节点，出口是美国静态住宅 IP，国内直连。

省事是省事，但有一点要特别注意：**一定要选 1 人独享。**

为什么呢？还记得前面说的，千万不要用万人蹬的机场节点吗？机场的 IP 是成百上千人在共用，很可能早就被 anthropic 标记过了。共享套餐也是一个道理：几个人用同一个 IP，用的人多了，照样可能被标记。你自己再小心，也挡不住别人把这个 IP 用脏。

**操作**

1. 在 ipequal 注册，购买套餐，**“使用类型”选 1 人独享**。我**没用过**，因为一直买不到，是看到很多大佬推荐才放在这里，建议先买一个月试试。
   - 还没有节点：[ipequal](https://www.ipequal.com/?ref=6adabd0307)（国内可直接打开）
   - 已经有节点：[ipequal](https://www.equaldcdn.com/?ref=6adabd0307)（需要开代理打开）
2. 复制订阅链接，按 [[导入代理软件]] 导入，**尽量通过剪贴板导入**。
3. 已经有别的节点的，也可以只让 claude 走住宅节点，见 [[常见问题#分流规则具体怎么写？|分流规则具体怎么写？]]。用了分流的，测 IP 之前要把 `ipinfo.io` 也加进分流规则，否则测出来的是原来节点的 IP。

“1 人独享”怎么确认真的只有你在用，见 [[常见问题#“1 人独享”怎么确认真的只有我在用？|常见问题]]。
