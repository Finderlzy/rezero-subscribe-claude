# IP 质量实测合集

这里收集了文中出现过的每一家商家的 IP 实测，选方案、选商家之前可以先看看。

先说清楚几件事：

- 每家只测了一次，只能代表测试那一刻、那一个 IP 的情况，不代表长期表现。
- 每个人拿到的 IP 都不一样。别人测出来好，不代表你拿到的也好，反过来也一样。
- 各检测网站的数据库和评分标准都不同，分数不能跨网站比较。怎么看各项结果，见 [[测 IP 质量]]。
