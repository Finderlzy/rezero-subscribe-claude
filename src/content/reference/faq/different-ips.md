# 测出来好几个不同的 IP？

ipinfo.io 上是一个 IP，商家后台写的是另一个，别的测 IP 网站又是一个，DNS 检测里还有别的……看懵了很正常。其实这几个 IP 各是各的东西，并不是哪里出错了。

先回忆一下方案一的结构：你的请求先到服务器，**只有 claude 和 ipinfo.io 再从服务器转给 ISP 出去**，其他网站都从服务器自己的出口出去（见 [[三、购买 ISP 代理]]）。按这个去对：

- **ipinfo.io 上看到的，是 ISP 的 IP。** 它是住宅 IP，claude 看到的就是这一个。
- **商家后台、别的测 IP 网站（比如 api.ipify.org）看到的，是服务器的 IP。** 服务器大多是机房 IP。ISP 的流量少，所以我只让 claude 和 ipinfo.io 走它，别的网站看到的自然就是服务器。
- **DNS 检测里列出来的，是 DNS 服务器的 IP。** 防泄漏那一步，我们让代理软件不在本地查电话簿，而是借用 Cloudflare、Google 这些大公司的 DNS 去查（见 [[防泄漏]]）。所以测出来的是它们的地址，不是你的，也不在国内，这正是我们想要的。
- **WebRTC 检测里 Local IP、Public IP 显示 `-`**，说明 WebRTC 已经被管住了，什么 IP 都没交出去，也是对的。
